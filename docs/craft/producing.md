## 0. 总纲：先读行业，再谈单兵（三个铁律）

**铁律 1 · 这是 0.1% 的生意**：2025 年参投微短剧超 19.2 万部，全年热力值破 5000 万仅 12 部，≈0.1% 爆款率〔DE-2026-01〕；热力值 <100 万的作品占 56.3%〔DE-2026-01〕。单兵产能追随机爆款 = 买彩票。**只打两类确定性：①评级/保底等资格赛（机构渠道）；②IP 改编**——2025 全网年度优质爆款 664 部中番茄 IP 改编占 413 部 = **62%**〔XJB-2026〕。账本永远按保底 = 0 规划：红果对 AI 仿真人剧的保底 2026 年从"最高 8 万/本 + 20% 分成"（1 月 29 日机制）一路收紧到 4 月底传闻取消、5 月部分成真、9 月"保底大降、只托精品"〔36KR-2026-03〕〔LJ-2026-05〕〔SINA-2026-09〕——**保底是 beta，不是常数**。

**铁律 2 · 先验证后放大**：好莱坞制片同样如此——开发期只回答"这个项目该做吗、能做吗"，绿灯（greenlight）后才进入花钱的筹备期〔VFS〕〔SB〕。落到单兵：免费/低成本流先验证商业假设，过质量门才投现金精渲；数据关之前不追加产能。

**铁律 3 · 求职期并行纪律**：制片是概率现金流，求职是确定现金流主线（现薪 23K → 期望 25-35K，AI 应用方向〔项目事实〕）。制片现金 ≤ 可归零上限、时间 ≤ 周产能上限、面试周自动降档。**别 All in**——参考产能数据再决定投入（§3.1）。

## 1. 立项决策

### 1.1 题材三层筛（行业数据为底座）

| 层 | 看什么 | 检索口径〔来源〕 |
|---|---|---|
| 供需 | 大盘规模 + 供给拥挤度 | 2025 逆袭题材热力值 143.9 亿、5178 部，规模与数量双第一 = **绝对红海**；现代、打脸虐渣均 125 亿+/5200 部 = 第一梯队拥挤〔DE-2026-01〕。**真正可打的蓝海在数据上长这样**：女性成长/亲情/穿越等中腰题材仅 800-1000 部却贡献 25 亿级热力，DataEye 明言"部分制作方可考虑深耕垂直用户"〔DE-2026-01〕 |
| 安全区 | 价值观导向（评级维度之一）、题材禁令、AI 政策 | 广电 2025-11 专项治理起 AI 漫剧纳入分类分层审核〔LMTW-2026〕；AI"偷脸"已出侵权判例〔XINHUA-2026〕〔RM-2026〕——安全区 = 合规层红线，见 §5 |
| IP 可得 | 授权渠道是否开给个人/小机构 | 抖音集团短剧版权中心 2026-03-09 上线漫剧 IP 库：**50 万+ 番茄原创 IP 开放改编，覆盖对公机构与个人达人**（签约模式二/三后申请）〔TVAO-2026〕；IP 改编爆款占 62%〔XJB-2026〕 |

**决策规则**：首部不正面刚 143.9 亿热力的逆袭红海；选「稳定垂类 × IP 库可得 × 合规安全」交集，用 §7.3 的数据回填修正。
**蓝海验尸法**：找到 5-10 部同类腰部剧，三问——还有没有在更？播放是否在涨？评论区是否催更？三问全否 = 蓝海可能是死海，弃〔【一人+AI 落地】〕。

### 1.2 一句话卖点

模板：**主角身份 + 反差/金手指 + 目标 + 第一钩子**。电梯测试：给不看短剧的人讲 10 秒，对方想点开才算过。对照好莱坞开发期工作：首版 synopsis 是制片人拿去卖钱/融资的核心物料〔NYFA〕——卖点不过 = 立项不过，改题材成本 ≈ 0，不值得为弱卖点付整部剧的钱。

### 1.3 目标平台与评级档位（立项即写死）

- 平台矩阵：主投 1 + 分发 N。量级参照：红果 2026-01 日活过亿、月活近 3 亿〔36KR-2026-03〕；红果 60 集及以上作品占 66%+、主流 60-100 集〔DE-2026-01〕。
- 档位二选一：**冲评级/保底资格** → 现金预算走 3-5 万〔项目口径·待核验，按档位反推见 §2.3〕精渲档；**长尾分账** → 免费流低成本档。
- 规则：立项卡缺「目标平台 + 目标评级档位 + 预算上限 + 备案/证照路径」四件套 → 不开机〔【一人+AI 落地】〕。

## 2. 预算模型

### 2.1 先认行业成本坐标，再定自己的目标线

| 口径 | 成本 | 来源/时期 |
|---|---|---|
| 传统动态漫 | 2000-5000 元/分钟 | 掘金实战指南〔JUEJIN-2026〕 |
| 早期 AI 漫剧（2025H1） | 1000-2500 元/分钟；单集(1.5-2min)1500-4000 元 | 掘金〔JUEJIN-2026〕 |
| 工业化 AI 漫剧（2026Q1，1-3 人 AI 全栈员） | <800-1000 元/分钟；单集 1200-1800 元；100 分钟全剧 8-12 万 | 掘金〔JUEJIN-2026〕 |
| 普通内容漫剧（2026 内卷后） | 已卷到百元级/分钟 | 短剧自习室〔ZHIHU-2026〕 |
| AI 仿真人剧（对真人） | ≤20 万/部，真人精品 ~150 万/部（-90%） | 海报新闻〔HB-2026-05〕 |

**注意**：上表多为"含人力的工具链成品价"。单兵自产现金只付引擎/配音/工具/IP 与合规费，**人力时间另行记账**（否则"零成本"幻觉会骗自己加产）〔【一人+AI 落地】〕。

### 2.2 两档质量流（免费流 vs 付费精渲，混合策略）

- **粗筛流（开发验证）**：能看清剧情、结构、节奏即可——验证"观众会不会看完"，不看画面精细度。成本 ≈ 引擎费下限。
- **精渲流（评级/申报/上线）**：角色一致性 + 精修 + 配音全上；达标才配评级。
- **混合纪律**：粗筛流先跑样片验证商业假设，**过 G2 商业关才允许精渲**；评级候选剧现金预算 3-5 万〔项目口径·待核验〕是精渲档封顶，不是起步价。参照工业化下限：100 分钟全剧现金 8-12 万是机构全成本线〔JUEJIN-2026〕——单兵现金预算显著低于它是正常的（人力不出钱），但**时间预算必须对等换算**。

### 2.3 成本科目表与 ROI

| 科目 | 成本性质 | 检索/项目口径 | 现金 / 时间 |
|---|---|---|---|
| IP 改编权 | 渠道授权 | 抖音漫剧 IP 库免费开放申请（一次申请 = 一个改编版本，解说漫不可）〔TVAO-2026〕；非库内 IP 走番茄版权合作单独采买〔TVAO-2026〕，2026 番茄 20 亿生态 + 短剧专项最高单书 60 万改编奖励〔STCN-2026〕 | 现金小/手续多 |
| 剧本 | token + 算力 | novel-agent 自产 ~0.6-0.8 元/万字符〔我方实测〕 | 现金极小，夜间批跑 |
| 图资产 | 角色/场景一致性（AI 漫剧多集稳定生产的第一瓶颈〔FEISHU-2026〕） | 一次建库全剧复用 | 现金 + 确认时间 |
| 视频算力 | 引擎 API | 单兵现金大头 | 现金 |
| 配音/字幕/剪辑 | 管线批跑 | — | 现金小 |
| 精修人力 | 机会成本 | 行业折算：工业化 100 分钟全剧 7-14 天、1-3 人 → ≈0.6-3.4 人时/分钟〔JUEJIN-2026〕 | 时间（记账） |
| 合规/证照/法务 | 见 §5 | 广电证/备案/授权链/形象自证 | 现金小 + 时间 |

**单集现金目标线** = 现金预算 ÷ 集数。例〔假设〕：评级候选剧现金 4 万 ÷ 60 集 ≈ **667 元/集上限**；参照 2026Q1 工业化单集成本 1200-1800 元〔JUEJIN-2026〕——差距全部由"自产人力 + 资产复用"填平，填不平就砍集数或降档。
**ROI 公式**（立项时算，保底按 0，全用保守概率）：`ROI = (Σ保底×P(达标) + Σ分账×P(上线) − 总现金−总时间折算) / 总投入`。
**应急金 = 计划现金的 25-30%**，预算 = 计划 × 1.3；动应急金必须在复盘说明；应急金耗尽 = 强制止损检查点。

### 2.4 省钱护栏（质量无损）

资产一次生成全剧复用（重复生成 = token + 一致性风险双烧）；静态提示词入可缓存前缀、批处理代替逐条调用（novel-agent 实测手法迁移）；省钱绝不砍质量门——砍冗余，不砍品控〔【一人+AI 落地】〕。

## 3. 排期与产能

### 3.1 单兵产能模型（用行业数校准自己的数）

- 行业锚：2026Q1 工业化工具链 1-3 人即可 7-14 天出 100 分钟全剧，≈0.6-3.4 人时/分钟〔JUEJIN-2026〕；个人实测级："一人一天做两分钟"〔YT-2026，经验帖〕；头部 AI 漫剧企业接入一体化工作流后产能 +30%〔PP-2026〕。**"AI 漫剧做一集不难，难的是多集稳定生产"**〔FEISHU-2026〕。
- 【一人+AI 落地】瓶颈 = 精修人时 + 生成排队；排队无人值守（夜间批跑），人只做确认/抽检/精修。每集记 `T_gen / T_queue / T_human` 三数，前 5 集校准。初估〔假设〕：粗筛流 T_human ≈ 0.3-0.5 h/分钟，精渲 ≈ 1-2 h/分钟（与行业 0.6-3.4 h 同量级）。
- 求职期周预算 ≈ 22h（工作日 2h×5 + 周末 6h×2），制片支线 ≤ 40% ≈ **9 h/周**；面试/笔试周降档至维护。

**结构性推论〔假设〕**：精渲 T_human = 1.5 h/分钟、9 h/周 → ≈ 6 成片分钟/周；60 集 × 90 秒 = 90 分钟 ≈ 15 周纯视频期。→ **求职期只跑到 M1-M3（样片 + 前 5 集 + 申报），全量 60 集是转全职或精修外包之后的事**。这是算术不是保守：求职期做全量 = 拿确定现金流赌 0.1% 爆款率。

### 3.2 分批交付里程碑

| 里程碑 | 交付物 | 出口 | 前置门 |
|---|---|---|---|
| M0（1 周内） | 立项卡（题材数据/卖点/平台+档位/预算/证照路径） | 立项 | G0 剧本门 |
| M1（2-4 周） | 样片 3-5 集（粗筛流优先） | 技术验证 | G1 技术关 |
| M2（M1+2-3 周） | 前 5 集完整版 | 商业验证 | G2 商业关 |
| M3 | 评级/保底申报材料包（过 G2 才做） | 商务 | — |
| M4 | 全 60 集，每批 10-15 集逐批过 G1 | 上线 | **求职期冻结此里程碑** |
| M5 | 上线 + D+7/D+30 数据关 + 复盘 | 学习入库 | G3/G4 |

### 3.3 与求职主线并行

剧本先行：60 集剧本求职期全做完（novel-agent 批跑）——剧本是免费前置产能；资产先行：角色/场景建库一次成型，不给 M4 留资产债〔【一人+AI 落地】〕。求职冻结：面试前 2 天 + 当天制片投入 = 0；offer 谈判期不启动新 M1。

## 4. 质量门管理（GO/NO-GO 体系）

框架来源：好莱坞开发期 = "Should and can this be made?"，产出"可行的创意+商业包"才绿灯〔VFS〕；筹备期先锁剧本、再拆解、再预算排期〔SB〕。本文件把这条流水线折叠成 5 道单兵可执行的门。

**G0 剧本门**（现金投入前，改题材成本 ≈ 0）：评级四维材料〔项目口径·待核验：故事完整性/人物塑造/价值观导向/市场适配〕+ novel-agent 番茄分/追读预测作 proxy + 题材数据表（§1.1）+ 卖点电梯测试。产出 = 未来申报材料草稿（§6.1）。

**G1 技术关**（样片）：① 角色跨镜一致性——AI 漫剧最大制作痛点〔FEISHU-2026〕，每集抽 3 个时间点对比 ② 口型/语音/字幕同步 ③ 无穿帮/明显形变 ④ 无肖像/版权雷（§5）。抽检：每集 3 时间点 + 全片 1.5 倍速跳看。

**G2 商业关**（前 5 集）：内测（目标用户 30-50 人）或平台小流量测试：3 秒留存 / 前 5 集完播 / 弃剧点分布。对标 = 同平台同题材腰部剧（基线缺失就自己锚：先取对标剧 7 日数据）。NO-GO 触发：完播显著低于对标腰部一半。

**G3 数据关**（上线 D+1..D+30）：看板 = 播放/人均时长/3 秒留存/全片完播/次日-7 日留存/付费点转化/单部 ROI。**止损触发器写死在立项卡，触发即执行**：D+7 完播 < 对标腰部一半 → 停后续批次、算力转下一部；D+14 付费点转化 < 平台均值 30% → 不追投不买量。参照：2025 年 56.3% 作品热力 <100 万〔DE-2026-01〕——没有止损线的单兵活不到下一部。

**G4 放大关**：单部 ROI ≥ 1.3（现金口径，保底 = 0）才加产能/加人；ROI ≤ 1 → 不加不多产，参数进知识库。

**坏片止损规则（铁律）**：① 止损点前置——现金花到 30%（样片完成时）= 强制 NO-GO 检查点；② 触发器写死立项卡，触发即执行，不"再等等"；③ 停 ≠ 白做——30 分钟复盘把被推翻的假设写进知识库；④ 禁止"追加救上一部"——追加预算 = 对新假设二次下注，重走 G0，动的是下一部的预算。

## 5. 合规与风控（2026 政策全景 + 单兵动作）

**自检时间线**：立项（题材/证照路径）→ 制作（虚拟形象/AI 标注/资产源档）→ 上线前（备案/许可证）→ 运营（政策双周扫描）。

**① 备案与证照（硬门槛，先核验后开工）**
- 广电 2025-02 起分类分层审核：投资 30 万-100 万的"普通"微短剧须报**省级以上广电**规划备案 + 成片审查；≥100 万或首页首推/招商主推的"重点"微短剧由国家广电总局统一备案公示〔NRTA-2025-02〕。
- 2025-11 广电专项治理**首次将 AIGC 类、漫画类纳入分类分层审核体系**，AI 漫剧按投资额分层、为中小/个人创作者降了备案门槛〔LMTW-2026〕。
- **2026-04-01 起 AI 动画微短剧"持证上岗"**：存量须在 2026-03-31 前完成备案补审否则强制下架，新增未审核备案不得上线〔LMTW-2026〕〔SOHU-ZZ-2026〕。
- 2026-07-30 总局令第 16 号《微短剧发展管理办法》正式立规：一类/二类微短剧备案由省级以上广电审核公示，重点扶持剧享有上线播出支持〔NRTA-2026-07〕。
- 资质：制作/发行/备案/版权交易的基础准入 = 《广播电视节目制作经营许可证》〔SOHU-ZZ-2026〕。上线须持《网络剧片发行许可证》或完成上线报备登记，片头按要求标注证号/备案号〔NRTA-2025-02〕。
- **单兵动作**：个人创作者通常缺机构主体——决策先做"主体三选一"核验：独资公司办理广电证 / 挂靠已签约机构 / 走平台个人通道（如漫剧 IP 库个人达人签约〔TVAO-2026〕），以当期平台+属地广电规则为准，不凭旧经验。**三件套归档：授权协议 + 改编权证明 + 备案回执/证号，缺一不上线**。

**② AI 标注与肖像权（仿真人红线）**
- AI 内容强制标注按平台与监管当期要求执行（平台标注 + 内容内标注双做）。
- **虚拟形象铁律**：2026-04-02 中广联演员委员会声明——未经本人书面正式授权严禁采集/使用/合成人脸〔XINHUA-2026〕；已有判例：深度合成"高度相似形象"侵害肖像权，**播出方未尽审查义务承担连带责任**〔RM-2026〕。锦天城法律指引同时提示：底层 IP 授权要覆盖"改编为 AI 漫剧"这一制作方式，AI 角色/真人相似度、提示词/三视图/分镜/成片的权利与字体音乐授权都要走查〔ALLBRIGHT-2026〕。
- **单兵动作**：角色一律纯原创虚拟形象；留存生成种子/参数/时间戳全链路源档用于自证非真人；不买"百元人脸"授权（黑产，见〔HB-2026-05〕）；立项即做相似度自检。

**③ 政策摇摆（红果保底事件全记录 = 风险教材）**
2026-01-29 红果升级剧本机制：互动 AIGC 仿真人剧本最高 8 万保底 + 20% 分成〔36KR-2026-03〕→ 春节前砍真人中小承制保底、力捧 AI 仿真人〔LJ-2026-05〕→ 4 月底市场传 AI 仿真人剧本全取消保底（红果否认，称部分保留）〔LJ-2026-05〕→ 5 月部分取消成真、工作室拒合作〔LJ-2026-05〕→ 9 月"剧本保底大降、只对精品托底，其余走分账"〔SINA-2026-09〕。
**落地纪律**：账本按保底 = 0；现金储备 ≥ 3 个月生活，制片可归零额独立；平台/素材/主体设计为平台中立（可迁红果/抖音/河马/番茄）；**双周政策扫描**（平台公告/版权中心/广电新规/判例），20 分钟，结论记一行日志。

## 7. 数据与复盘

### 7.1 上线数据看板（每部一卡）
播放 / 人均观看时长 / 3 秒留存 / 全片完播 / 次日-7 日留存 / 付费点转化 / 单部 ROI。平台后台 + 自记发布时序表（发布时间/批次/动作要对得上数据拐点）。

### 7.2 复盘模板（D+7、D+30，每次 ≤ 30 分钟）
**假设表**：立项时写 3-5 条可证伪假设（例："中腰垂类 3 秒留存 > 逆袭题材"），每条标 验证/推翻 + 证据行 + 对下一部影响。**四问**：哪条假设被验证？被推翻？哪一集完播断层（逐集找弃剧点）？下一部改什么？

### 7.3 爆款学习闭环（数据回到下一部选题）
1. 数据回填 §1.1 题材数据表——下一部立项直接消费；
2. 素材自沉淀：高完播的开场/钩子/卡点/悬念断点切片入 style 库（照 novel-agent own-style 银行：0 LLM、封顶 30 条）；
3. 外部拆解：每周拆 1 部爆款，**重点拆 IP 改编**——爆款 62% 来自番茄 IP〔XJB-2026〕，拆 IP 题材共性 + 开篇结构；
4. 组合复盘：每季度算 N 部 ROI 分布 → 决定放大/加人/转全职（§8）。

## 8. 团队化预备

### 8.1 行业对照（别人怎么组产能）
灵矩动漫两三个月拉起 200 人 AI 漫剧团队，2025-09 稳定月产 30 部〔ZHIHU-2026〕；但 2026Q1 工业化工具链已把门槛压到 **1-3 人（AI 全栈员）7-14 天 / 100 分钟**〔JUEJIN-2026〕——个人工作室与 200 人公司的产能差正被工具抹平。**先工具化，后加人**〔【一人+AI 落地】〕：工具链只解决产能，不解决判断——判断 = 本文件的门与复盘。

### 8.2 单人瓶颈信号 → 加人顺序
信号：① 精修/排队 backlog > 2 周且数据已验证值得放大 ② 发行与账号运营吃掉制片时间 ③ 连续 2 部过 G3 但产能上不去。
顺序（剧本已自产不加编剧）：① 视频精修/剪辑外包按量（卡产能处先外包）→ ② 账号运营/数据专员（矩阵时）→ ③ 制片助理（排期/合规/申报文件）。
触发（if-then）：外包 = 单部 ROI ≥ 1.3 且有连续批次需求；固定人力 = **月现金流（保底按 0）≥ 人力月成本 × 1.5 且连续 2 个月**才签，否则永远按量外包。求职期不触发本节。

### 8.3 交接清单（一人 → 小团队）
资产：角色/场景源档树 + 生成链路、项目目录、知识库（本系列文档 + 复盘结论）、账本；流程：本文件 = 制片主流程、各质量门 = 检查点；账号：平台/引擎/备案主体清单与权限；SOP：批次进度 / 政策双周扫描 / 数据抽检。
