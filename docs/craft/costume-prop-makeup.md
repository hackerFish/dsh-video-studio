## 0. 总纲：三道铁律与预算纪律

### 0.1 服化道要专业，先认三件事（行业共识）
1. **服化道的形制、纹样、布料、裁剪须符合设定时代与生产力水平**，且服装要为角色服务：季节、场合、身份、性格、心境〔S2〕。写实风格要考证史料，款式/材质/纹样逐项对档〔S1〕。
2. **造型夸张但不失内在逻辑**——哪怕奇幻题材，服装也必须从角色内质出发、族群/门派/势力在视觉上分明〔S1《星战》《指环王》案例〕。
3. **细节决定口碑**——观众拿放大镜追剧，一个曲别针都能让口碑滑坡；考据与细节现在是流量密码〔S13〕。
→ 落地：以上三条翻译成一条资产层铁律——**服装/妆发/道具/场景，一切只在档案里定义一次，生图提示词一律引用名字（`wear: outfit_02_combat`），绝不现场重写。**

### 0.2 三条执行铁律
1. **一次定义，处处引用。** 档案是唯一事实源；重写描述 = 漂移〔S8：漂移是生成采样的默认行为，文本必须作为可检索的显式约束与参考图并存〕。
2. **参考图锁「具体形态」，文字锁「语义与时代」，两者缺一不可。** 只有图：纹样会被抄错；只有字：形制会被画歪〔S8：Character DNA 文本与多角度参考图是同一资产的两种表达〕。
3. **头面部是最高优先级锁区**：脸 > 发型+发饰 > 服装主结构 > 纹样 > 首饰 > 道具。预算有限时从上往下保。
→ 落地：AI 建模时把「锁定优先级金字塔」写进提示词区块顺序（权重=顺序），与鲸影 PROMPT-ENGINEERING 十原则的"区块化分层"一致。

### 0.3 @绑定 30 图预算纪律（鲸影内部纪律）
- 单人近景 = 正脸 + 发型发饰特写 + 服装细节 = **3 张**；单人全身 = 正脸 + 该套定妆全身 + 标志道具 = **3~4 张**；双人 ≈ 每人 3 + 场景 1 = **7 张封顶**。
- 群像/大场面：只给主角与领衔配角绑图（各 2 张），路人靠 §5.4 刷色分级，**不绑图**。
- 参考图质量门槛：清晰对焦、均匀光、中性背景、短边 ≥1024px；糊图、强阴影、极端角度都是负资产〔S10〕。
- **每个角色先单独锁定、测试通过，才允许与第二人同框**——多角色同框是漂移放大镜〔S10〕。

### 0.4 2026 行业新实践（补充，比原任务 context 更新）
- 多视图参考格（Grid/Turnaround：正面+侧面+背面+四分之三）是比单张人像更强的 3D 约束——单正脸在转面时必崩；**背面、四分之三视图是参考图里的必选项**〔S6〕〔S7〕。
- 高量产零漂移的"金标准"是 LoRA 微调（15–50 张角色图），做 IP 化长剧集时值得排入远期技术债〔S7〕；现阶段管线以多参考图 @绑定为主。
- 服装出图先进"纯服饰定妆"（无人物、单色背景、全结构展示），确认结构后再套到角色身上〔S11〕——对应本管线的 master asset 服装定妆特写。
- 角色一致性本质是**管线设计问题而非提示词技巧**——鲸影把定妆做进 master asset 层正是正确方向〔S8〕。

## 1. 服装设计语言：服装是角色的第一句台词

### 1.1 动手前先答五个问题（改编自行业"服装为角色服务"原则〔S2〕）
① 身份（职业/阶级/门派）② 性格（外放/内敛/狠厉/温吞）③ 立场（正/邪/亦正亦邪，用色即立场）④ 经济（华服要有地位支撑，破衣要有来由）⑤ 本场景目的（这套衣服要帮这场戏干什么）。答不出 ⑤ 的衣服不设计。
- 例证：87 版《红楼梦》林黛玉常偏发+鲜花饰（灵秀少女），薛宝钗发式端正+贵重金饰（稳重端庄），王熙凤艳色暴露（开放个性）——同剧身份/性格/阶层全靠服装细节区分〔S2〕。
→ 落地：答案 ②③④ 直接写进角色档案「人设」段，答案 ①⑤ 写进每套 outfit 的「用途」字段（§2.1），作为设计评审的验收项。

### 1.2 颜色心理学速查（用色即人设，全剧锁死）
色彩没有好坏，只有搭配；色彩对人的心理作用有体系性研究〔S14〕。影视写意色彩有经典语义：红=热情/创造与毁灭，蓝=神秘/冷淡，白=和平/结束，黑=稳重/威严/冷静思维，绿=生命/自然/和平〔S1《英雄》〕。
| 色 | 语义（综合〔S1〕〔S14〕） | 常用身份 |
|---|---|---|
| 纯白/素白 | 出尘、孤高、结束 | 仙门真传、谪仙、素衣角色 |
| 玄黑 | 威严、杀伐、藏锋 | 暗卫、宗主、黑化态 |
| 正红 | 张扬、喜庆、危险 | 战袍、婚服、魔教 |
| 青/黛蓝 | 温润、克制、仙气 | 正道内门、书生、医者 |
| 玄紫/暗紫 | 神秘、高位、亦邪 | 魔尊、高位反派 |
| 灰褐/麻 | 底层、隐忍、市井 | 杂役、平民、探子 |
| 金/明黄 | 皇权禁色 | 帝王一人，余者僭越 |
→ 落地：规则——**主色 1 + 辅色 1 + 滚边/点缀色 1，至多三色**（颜色越多越易漂）；定色用传统色名（月白/黛青/玄黑），禁"深色/好看的颜色"；仙门安全组合=蓝+白+银，魔道=红+黑+金，定组合再填人设。

### 1.3 剪裁与轮廓语义（写进档案的"轮廓词"）
汉服体系的关键认知：宽袖为礼服、窄袖为常服，宽窄搭配是"礼服宽博、常服便捷"的完整体系；平面剪裁、无现代立体省道〔S3〕。
| 轮廓词 | 语义 | 依据 |
|---|---|---|
| 宽袍大袖（H 垂坠） | 飘逸、清贵、礼服感 | 褒衣广袖，圆袂象天〔S3〕 |
| 束腰窄袖（X 收腰） | 利落、武力、行动力 | 常服窄袖便捷〔S3〕 |
| 层叠宽下摆 | 威仪、权力、仪仗 | 礼服重工层叠〔S3〕 |
| 短打/轻甲 | 赶路、战斗、市井 | 功能写实〔S1〕 |
→ 落地：轮廓词与剪裁词（交领右衽/齐胸襦裙/马面裙/圆领袍）**原词入档**，是生图防"古装变现代 Lolita/舞台服"的第一道闸〔S11〕。

### 1.4 材质即阶级（且材质是 AI 高频漂移点）
材质直接标记阶级与身份——贵者绸缎织金、贱者粗麻葛布〔S2 案例：粗布破衣区分匪首与部下〕。
→ 落地：材质词入档禁换（如"哑光提花绸"≠"棉麻"≠"缎面反光"）；同一套衣服跨镜头缎↔棉麻跳变是高发事故，材质必须配服装细节特写参考图兜底。

### 1.5 服装矩阵：每个角色的"衣柜"（默认六套位，每套独立定妆一次）
| 套位 | 名称 | 何时穿 | 要点 |
|---|---|---|---|
| 常服 | outfit_01_casual | 日常文戏 | 决定观众第一印象，质感投入最高 |
| 行动装 | outfit_02_combat | 战斗/赶路/潜入 | 束袖束腰，动作不穿帮 |
| 盛装 | outfit_03_ceremonial | 大典/宴/婚 | 全剧最重工，象征位阶 |
| 便装/夜行 | outfit_04_stealth | 暗线、市井探访 | 低饱和，可卸身份标识 |
| 私服 | outfit_05_home | 室内关系戏 | 卸下身份的瞬间，最见真心 |
| 特殊态 | outfit_0X | 囚服/丧服/伪装 | 剧情需要时增，用完可下线 |
- 参照系：《红楼梦》人物"不同时期、不同身份的着装转换"恰当地表现性格与心境变化〔S2〕——不是越多越好，是**切换即剧情**。
→ 落地：每套 = 独立 outfit_id 独立定妆图；分镜只写 `wear: outfit_id`。

### 1.6 跨集换装规则（鲸影纪律）
- 换装是**剧情事件**不是美术偷懒：一集内单角色至多 2 套切换，切换点固定在大场景转换处。
- 换装必须显式声明（§2.3），画面内完成或台词交代；**禁无缝瞬移换装**。
- 衣柜**只增不删**：某套一旦定妆登场，日后任何一集再出现必须逐字一致。
- 连续三集穿同一套常服是正常的；每集三套新衣才是穿帮。

### 1.7 古装玄幻的服饰体系（安全区主战场）
仿真人剧主攻玄幻/仙侠大场面。先给世界观定两行字段，再谈设计：
1. **时代骨架**：架空也必须有主体形制。真实形制常识（公开考据〔S3〕〔S4〕〔S5〕）：汉服四大核心 = 交领右衽、褒衣广袖、系带隐扣、平面剪裁；形制分衣裳制（冕服玄端·顶级礼服）、深衣制（曲裾→直裾）、襦裙制（齐胸/齐腰/明制袄裙+马面裙）；另有褙子、半臂、披风、直裰。朝代气质：先秦古朴、汉雄浑、魏晋飘逸、唐丰腴华丽、宋素雅、明规整华美〔S3〕。
   - 例：`明制为骨 + 架空仙门元素`，还是 `魏晋风为骨`。无骨架 = 形制大乱炖。
2. **等级色板**：全剧各势力一行"底色梯度"。正道仙门例：外门灰 → 内门青 → 真传白 → 长老墨青 → 宗主玄紫金边。**等级靠颜色梯度与滚边/纹样复杂度表达，不靠整衣换款**——同门同款不同色，辨识度与成本双赢。
- **形制红线（防 AI 低级错）**：
  - 交领必须**右衽**：左衽=逝者丧服/异族之俗，生人穿左衽是古装剧硬伤〔S3〕〔S4〕。
  - 纽扣是**元代后才出现**的；汉唐宋主题出现满身盘扣/现代扣件即穿帮〔S5〕。拉链/子母扣/松紧带直接进负面清单。
  - 宫廷品级靠纹样与补子表（文禽武兽）区分〔S1《投名状》补子考据案例〕；五爪龙/十二章为皇权禁物，路人禁龙纹、禁正红，这是防"草民穿龙袍"的粗鲁穿帮。
  - **架空剧也先别急着混搭**：参考《绣春刀》——按明代发掘样式再提炼发挥，是"虚实结合"的正面教材；观众能接受的架空是"有来由的改"，不是乱拼〔S1〕。
→ 落地：每势力一行 `势力色板` 入档案；`时代骨架` + `允许的架空元素` 两字段入世界观档案，全管线引用。

## 2. 一致性锁（AI 语境核心）

### 2.1 一套服装 = 一条档案记录（字段即提示词来源，可直接落库）
```
outfit_id: outfit_02_combat        # 全剧唯一，分镜只引用这个
用途: 战斗 / 赶路                   # §1.1 之⑤，决定哪些场景允许穿
款式: 束腰窄袖劲装，X型收腰，交领右衽，下摆至膝上   # 剪裁词原样，防变 Lolita〔S11〕
主色: 玄黑  辅色: 暗红  点缀: 银灰滚边              # 三色封顶；色名精确〔S1〕〔S14〕
材质: 哑光织锦，无强烈反光                        # 材质词禁换
纹样: 领口袖口一圈暗银缠枝纹（小面积，非满铺）        # 纹样=最小可复述单元
配饰: 银质护腕×2、腰间暗红宫绦 + 玄铁令牌
发型: <引用 head_hair_02>            # 发型永远独立于服装，不写进服装段
禁漂移项: 护腕必须成对；宫绦系腰右侧；玄黑不可变灰黑
参考图: ref/costume/char_女主_outfit02_front.png  +  detail.png（领口纹样特写）
```
设计动机（来源侧）：AI 漫剧服装事故 = 结构混乱、袖子左右不一致、腰带位置错、裙摆层数随机、配饰堆叠、颜色失控、换镜头即变装〔S11〕——字段式描述按 **结构 + 材质 + 配色 + 配饰 + 状态** 拆分，正是对冲这些事故〔S11〕；CSS 同源思路：**颜色锁定到"占比"**（如冰蓝45%/樱粉25%/珍珠白20%/金10%）比"淡蓝色"稳一个数量级〔S11〕。
→ 落地：生图提示词 = 角色档案 + `wear: outfit_02_combat` + 逐字粘贴字段描述，**一字不改**；色占比法可作每套的"配色视觉权重"字段（盛装/礼服强烈建议写，主色≥40%）。

### 2.2 锁定优先级金字塔（预算分配与精力排序）
```
      脸（五官锁，最高）
   发型 + 发饰（最高频穿帮点）
  服装主结构（款式轮廓）
   纹样（特写参考锁）
    首饰（耳饰/戒指/玉佩）
      道具（辨识点锁）
```
依据：AI 一致性锁必须逐元素显式声明——face/hair/outfit/proportion 分开锁比一句"保持一致"有效〔S9〕；一次一变（pose/lighting/environment/expression 每次只动一个轴），先锁后变〔S6〕。
→ 落地：档案「特征锁定」字段与提示词一致性锁都按金字塔分元素写（脸一致/发型一致/服装一致/道具一致 分句），与鲸影 PROMPT-ENGINEERING"三重锁"一致。

### 2.3 换装 = 显式切换声明；不换 = 全管线禁漂移
镜头元数据必须带服装状态：
- `wear: outfit_02_combat`——沿用即"什么都不用改"，但任何镜头禁把衣服画变样；
- `change_outfit: outfit_01_casual → outfit_03_ceremonial @shot_0027`——换装是剧情事件；
- `state_add: 右臂衣袖破损+血迹 @shot_0053`——损伤是"加料"不是"重画"。
→ 落地铁律：**加状态词，不改基础描述**。脏衣破衣镜头 = 原套描述 + 局部追加，绝不重写一件"看起来像"的脏衣服。本规则与 Runway 建议同构：让参考图管外观，提示词只管场景与状态〔S10〕。

### 2.4 参考图该锁什么（性价比排序）
高价值：① 服装正面定妆全身 ② **背面视角**（AI 正脸无敌、后脑勺全凭脑补；转面/背面是参考系统的公认弱区〔S7〕）③ 发型发饰特写 ④ 纹样领口细节 ⑤ 正脸。
中价值：侧后角度、动态衣摆、武器握持手型。低价值：多张相似全身。
- 多视图组合标准：正脸人像 + 侧面/四分之三 + 全身；所有参考图必须是同人同设定〔S10〕。
→ 落地：每套服装必须配一张**背面定妆**；@30 额度里发型背面特写是常驻项。

### 2.5 描述词纪律：确定性词表 vs 模糊词表
| 写（确定性，来自档案锁定字段） | 禁写（模糊/易漂） |
|---|---|
| 玄黑、月白、黛青（传统色名） | 深色、浅色、好看的颜色 |
| 及腰长发、齐眉刘海、枕骨上方高髻 | 长发、盘发、漂亮的发型 |
| 右衽交领、束腰窄袖、马面裙 | 古装、汉服风、仙气飘飘 |
| 银步摇×1 斜插左侧鬓发 | 发饰、头饰、点缀 |
| 哑光提花绸 / 粗麻 | 面料、材质 |
依据：多视图一致性要求"描述越具体，模型可跨视图维持的材料越多"——精确发长、精确颜色、具名衣件〔S9〕；参考图+`same character, preserve face geometry and hairstyle, keep costume motif X` 的模板句式可迁移〔S6〕。

## 3. 道具设计

### 3.1 先分两类
- **功能性道具**（兵器/法宝/日常器）：随人走，核心是**辨识度 + 使用逻辑**。
- **象征性道具**（麦高芬）：贯穿全剧的信物，核心是**独一性**——在一堆同类物里一眼可认，每次出现一模一样。
参照系：《指环王》各族群连武器铠甲都按文化统一设计，族群视觉分明〔S1〕；《甄嬛传》连安陵容赶路的马车灯笼都贴合人物境遇——道具是叙事的组成部分〔S13〕。
→ 落地：麦高芬（信物/玉佩/断剑）必须进主角定妆卡的「标志性道具」字段并绑参考图，它是跨集"剧情连续"的视觉锚。

### 3.2 道具卡模板
```
prop_id: prop_sword_赤霄      归属: 男主（绑定角色，不换主）
类型: 兵器（功能性）/ 信物（象征性）
形态: 剑，剑身长=角色身高1/2；剑身赤红流光纹；剑格龙纹玄铁；黑底描金鞘
辨识点（≥2个，缺一不认）: ①赤红剑身 ②龙纹剑格
色光: 出鞘流光=赤红（全剧唯一，不与任何法宝同色）
出现规则: 战斗/拔剑场合出现；日常随身只露剑鞘
参考图: ref/prop/赤霄_front.png + 剑格特写.png
```

### 3.3 兵器/法宝一致性要点
- **发光 = 锁死**：法宝/剑光颜色与形状全剧唯一，禁两法宝同发光色，否则打戏分不清敌我。
- **尺寸锚点**防 AI 尺度崩坏：剑长≈角色 1/2 身高（写进形态描述），匕首不过前臂，枪比人高——无锚点就会画飞。
- 器物文字默认全无：AI 假字/错字是成片级事故〔S12〕，要刻字只许在定妆特写人工精修。
- 半实体法宝（灵珠/符箓/魂器）形状极易飘，必须绑定角色 + 高频小物给特写参考。

### 3.4 跨镜头复用与"手-物"冲突
- 同道具跨镜头一律引用同一参考 + 同一段形态描述；新增道具 = 新增道具卡，禁止"顺手画个相似的"。
- 握持动作词化（"右手反握剑柄，剑身垂于身侧"），不给 AI 自由发挥"握着"——自由发挥必出剑穿手。
- 特写镜头让手远离宽袖/流苏/飘带边缘：垂坠织物 + 手指同框是畸形高发区〔S11 结构混乱类事故〕。

## 4. 化妆造型

### 4.1 化妆 = 面部上色版的特征锁定（基础妆全剧锁死）
```
makeup_base:
肤质: 冷白哑光陶瓷感（仿真人肤质词，非卡通）
眉: 剑眉，灰黑色，眉峰略锐
眼: 上挑眼线，大地色眼影，浓长睫毛
唇: 正红哑光
颊: 无腮红（清冷系）/ 淡杏腮红
```
→ 落地：妆面是**独立特征锁定字段**，与五官锁分列；生图时原样复制，不进任何"情绪形容词"。
依据：仿真人写实风忌厚重妆感——行业写实造型讲究"于精微中见广大，不夸张但提炼典型"〔S1 现代写实风格节〕。

### 4.2 基础妆 vs 功能妆分离：加妆，不改底
| 妆态 | 处理方式 | 归类 |
|---|---|---|
| 日常 | 引用 makeup_base | 档案常驻 |
| 黑化/魔化 | base + 新妆态 id「眼尾上扬烟熏 + 暗紫唇色」 | 剧情事件，登记入档 |
| 哭泣 | base + shot 级「眼眶泛红、鼻尖微红」 | 临场加词 |
| 受伤 | base + shot 级「嘴角血污、颧骨擦伤」 | 临场加词 |
| 年龄切换 | base + 「眼尾细纹、法令纹、肤色加深」 | 若角色有前世/老年态则入档 |
→ 落地纪律：**情绪的妆是"加词"，身份的妆是"换档案"**。哭一场画成黑化妆 = 底层错误。对应 §2.3 加状态不改基础。

### 4.3 年龄感与黑化表达（仿真人语境）
- 年龄感靠**建模**（骨相/肤质/纹路）打底，妆面只做少量提示，禁浓妆扮老扮嫩。
- 黑化最快三件小事：眼线角度（下垂→无辜 / 上挑→狠厉）、唇色饱和度、眉形锐度。别上大浓妆。
- 发型也是年龄/身份编码（考据向）：87 版《红楼梦》无刘海抹额=已婚妇人、有刘海=少女〔S2〕——奇幻剧不必照搬，但"发型随身份/年龄切换"本身要作为设定写入。

### 4.4 发型：最高频穿帮点（全剧最容易崩的就是它）
行业侧证据：观众吐槽重灾区是"雪白假发套假得明显""发型敷衍雷同"〔S13〕；AI 侧同样——发型被公认为"生成间最容易变化的部分之一，值得单独命名"〔S6〕。
锁五件事，全进档案特征锁定字段：
```
head_hair_02:
发色: 银白，发梢带蓝黑渐变         # 色名精确、渐变方向写死；忌惨白塑料感〔S13〕
发际线: 中分，额前两侧留长鬓垂至颧骨
髻形: 单螺髻高束脑后上部，垂发至腰    # "位置+长度锚点"，禁"好看的发型"
刘海: 齐眉碎刘海（向右分）           # 方向写死
发饰: 银步摇×1 斜插左侧鬓发 + 顶部小银冠  # 左右、数量、类型全写死
```
→ 落地三条铁律：
1. **发饰属于发型字段，不属于服装**——它跟脸走；写进"盛装"服装段 = 日常镜头必消失。
2. 束发/披发是**状态不是默认**：写清"束发"或"披发"，转换 = 显式状态切换（挣扎/受伤后散发要登记）。
3. 中长发角色必须有**背面+侧面定妆参考**（〔S7〕转面崩坏区）；打戏/风动镜头禁"长发飘动"自由词，必要时补"束发不乱"。

## 5. 场景陈设：环境即人物

### 5.1 环境即人物
主场景 = 主角的说明书。先问：这间房想让观众给角色加分还是减分？
- 陈设透露三件事：身份、经济、心性（一丝不乱=自律 / 酒坛遍地=自弃）。
- 参照系：《甄嬛传》后宫茶具摆件与人物境遇呼应、炭火从 60 多箱中精挑〔S13〕；《觉醒年代》陈独秀吃火锅掉落的辣椒籽成为"细节口碑"密码〔S13〕。
→ 落地：每个场景挑 **3~5 件标志性陈设（styling anchors）** 写进场景卡，镜头只要带到房间它们必须在——它是观众确认"还是那间房"的锚。

### 5.2 场景卡模板
```
scene_id: scene_客栈_悦来楼     所属: 中立驿站型场景
时代锚: 明制为骨
主结构: 二层木楼，柜台靠右，楼梯正对门，酒坛阵沿墙
标志陈设（锚点3~5件）: ①门口酒幌 ②柜台算盘 ③柱挂红灯笼×2 ④二楼雕花栏杆
光=时态（变光不变陈设）:
  晨: 冷灰天光侧窗 / 午: 暖黄高反差门光 / 夜: 烛火暖橙灯笼主光 / 雨: 青灰低饱和湿反光
参考图: ref/scene/悦来楼_master_昼.png + _夜.png
```

### 5.3 场景资产库与跨集复用
- 同一场景 = 同一 master 参考 + 同一陈设清单，**跨集引用不重造**。第 3 集回悦来楼，陈设一个字不许动——观众记不住装修，但记得住"灯是不是那盏"。
- **光 = 时态字段**：陈设不变、光线变。夜戏换夜参考或加光场词，绝不重画场景。
- 穿帮案例：古装剧曲别针挂灯笼、话筒入镜这类"小物件失误"都能破圈毁口碑〔S13〕——陈设锚点是场景的"禁漂移项"，进质检清单。
- 主场景（卧室/大殿/基地）出镜率高，参考图质量最高；一闪而过的小场景可用弱参考 + 文字。

### 5.4 大场面 / 群像：刷色分级法（安全区主场）
- 群像前先出**势力色板表**（谁穿什么色系），路人按势力刷色。
- 主角保辨识、路人保层次：主角穿势力色板最高对比档（全场灰蓝中一点白或红）；路人全部降饱和。
- 远景只保"色块对"，近景才给脸——群像不给路人绑参考图（§0.3）。
- 主体与背景分离：主角服装色禁与场景主色同调（红衣主角别放红墙大殿）。依据：族群/群体"视觉上分明"是好设计的共性〔S1《指环王》〕。

## 6. AI 特有风险清单（生图前后对照检查）

| # | 风险 | 典型表现 | AI 侧对策（来源） |
|---|---|---|---|
| 1 | 衣料文字/纹样乱码 | 伪汉字、假字、错字 | 常规镜头无字；刻字只做定妆特写人工精修〔S12〕 |
| 2 | 结构混乱 | 上衣裙子结构混乱、袖子左右不一致、腰带位置错 | 按 结构+材质+配色+配饰 字段拆分描述〔S11〕；剪裁词原样引用 |
| 3 | 形制混搭/时代错位 | 左衽、满身盘扣在汉唐、现代扣件 | 时代骨架字段；负面清单挂"现代扣件/拉链/松紧带"；左衽硬伤见〔S3〕〔S4〕，纽扣年代见〔S5〕 |
| 4 | 等级僭越 | 路人穿龙纹/正红 | 势力色板+纹样禁区随档案分发；群像刷色分级 |
| 5 | 发型崩坏 | 束发变散发、刘海换边、发色渐变反向、假发感 | §4.4 五锁字段逐字引用 + 背面特写参考；发色忌塑料白〔S13〕 |
| 6 | 首饰/发饰漂移 | 耳坠变、步摇左右换、消失 | 头面部锁区参考每镜头带；对称简单款优先；位置写"左/右" |
| 7 | 手与服装冲突 | 手指穿袖/衣带、握剑畸变、多指 | 握持动作词化；手指进负面清单；特写避开飘带流苏边缘 |
| 8 | 材质/颜色漂移 | 缎↔棉麻跳变、灯下衣服变色 | 材质词入档禁换 + 细节参考；换场景光词不改衣色词；夜戏给夜参考 |
| 9 | 复制人 | 群像路人脸/衣与主角雷同 | 群演刷色远离主角特征色；只给主角领衔绑图〔S10〕 |
| 10 | 尺度崩坏/配饰堆叠 | 匕首比人长、头饰插穿、满身配饰 | 道具卡尺寸锚点；"配饰堆叠过多"进负面〔S11〕 |

### 7.2 服道化质检清单（镜头级抽检，出片前逐项过）

- [ ] 妆面：与 makeup_base 一致？情绪加词未越界成"换妆"？
- [ ] 服装：款式/三色/材质/纹样与当镜 wear 声明一致？破损血迹只在声明镜头出现？
- [ ] 结构：袖/带/裙摆结构无混乱、左右对称？
- [ ] 首饰：成对成单合设定？无消失/换位？
- [ ] 道具：辨识点都在？尺寸合锚点？发光色唯一正确？
- [ ] 文字/纹样：无假字乱码？无僭越纹样？
- [ ] 形制：无左衽/时代错位扣件/跨代拼接？
- [ ] 场景：标志陈设齐？光=当前时态？无陈设漂移？
- [ ] 等级/群像：无路人穿主角色/禁色？主角与背景色分离？
- [ ] 手与服装：无手指穿袖/握持畸变？
- [ ] 跨集记忆：复用旧场景旧服装时，与历史镜头同款同貌？
