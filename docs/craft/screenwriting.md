## 0. 编剧在管线里的产出物

| 阶段 | 编剧视角产出 | 一句话验收标准 |
|---|---|---|
| story | 选题卡片（题材/卖点/差异化）、人物圣经（欲望/缺陷/弧光/反派四层）、总纲（主题一句话 + 主线一句话 + 节奏段划分） | 给外行讲 10 秒卖点，对方想点开 |
| script | 分集目录（每集钩子类型 + 🔥重点集 + 💰卡点标注）、逐集剧本 | 每集都有 1 个导演意图、1 个情绪转折、1 个尾钩 |
| 交付前 | 剧本医生报告（五维打分 + 问题分级 + 修改优先级） | 50 分制 ≥38 才允许进 storyboard |

铁律：**编剧永远写给"会滑走的观众"看，不是写给导演看。** [行业2026] 红果官方课：短剧前 3 集若不能激发兴趣、传递情绪、埋下悬念，观众不会给第 4 集机会〔S4〕。

## 1. 选题立项：先选对战场，再谈才华

### 1.1 题材供需判断（数字口径沿用 producing.md §7.3 已核裁决，不重复造数）

| 战场 | 数据 | 裁决 |
|---|---|---|
| 逆袭题材 | 2025 热力值 143.9 亿 / 5178 部，规模与数量双第一〔数据 S14〕 | **绝对红海**，首部不正面刚；任务口径"222 亿播放"未获源，弃用 |
| 玄幻/仙侠 | 约 140 亿稳定盘〔S14 同源口径，玄幻具体数值待核〕 | **稳定盘**：量大不掉、竞争烈度低于逆袭，且是仿真人题材安全区（见下） |
| 异能低供给 | 无公开来源〔producing.md §7.3 标"待核验"〕 | 蓝海假设成立但需**蓝海验尸法**验证：找 5–10 部同类腰部剧，问"还在更吗/播放涨吗/评论区催更吗"，三问全否 = 死海〔producing.md §1.1〕 |
| IP 改编 | 2025 爆款 664 部中番茄 IP 改编 413 部 = **62%**〔数据 S15〕 | 自带 IP（novel-agent）是零版权现金的第一通道；番茄库已开放 50 万+ 部、全线上申请（business.md §2.2） |

**[AI落地] 仿真人题材安全区是编剧的硬约束，先于市场判断**：[行业] 仿真人剧识破点集中在微表情/眼神不聚焦 → 现代都市情感、大量面部特写 = **高风险**；玄幻/仙侠/大场面 = **安全区**（非现实语境降低"像不像真人"审判标准）。**选材第一定律：仿真人剧的题材天花板由模型缺陷决定，不由剧本才华决定**（COMMERCIAL-PLAYBOOK §3.4）。→ 逆袭/打脸类若必须在都市发生，把"身份舞台"搬到架空/玄幻语境重写。

### 1.2 一句话卖点公式

`主角身份 + 反差/金手指 + 目标 + 第一钩子`。例：`弃世剑尊（身份）转生废柴嫡子（反差），为护家人重登仙途（目标）——第一集开棺，他发现自己坟头的草被人踩秃了（钩子）`。
电梯测试：给不看短剧的人讲 10 秒，对方想点开 = 过；卖点不过 = 立项不过，改题材成本 ≈ 0，不为弱卖点付整部剧的钱〔producing.md §1.2〕。
- 国际对照〔S18〕：logline 母版 = `一个[有缺陷的主角] 必须在[倒计时]前达成[可见目标]，否则[赌注]`，一句话 ≤30 词；want（外部可见目标）与 need（主题）反向拉扯至终局才合流。**中外差异**：中国公式强“身份反差”，好莱坞补的是**时钟 + 赌注**两元素——给卖点加“三日内 / 否则满门皆灭”级约束，钩子硬度立升（本库公式按国际补齐）。
- 测试先行优于拍脑袋：MPA 把“创意测试更快 → 命中率上升”列为 ReelShort 扭亏第一驱动〔S21〕；选题定稿前按 Vertical Haus 纪律小测：5 个标题 × 3 张缩略图方向 × 3 条切片预告，看数据不看自嗨〔S20〕。

### 1.3 差异化策略（AI 同质化是 2026 头号死因）

- [行业2026] 听花岛："只要市面上爆过的题材，我们不跟风做，要做制造流行的人"；短剧迭代"每三个月颠覆一次"，剧本写好两个月可能已过时〔S9〕。**AI 产能泛滥让"千剧一面"贬值更快**（月上新约 3.8 万部 AI 剧〔数据〕）——同质化模板的边际价值趋近于零。
- [行业2026] 燕北工作室"微创新四式"（不颠覆、只换参数）：① **形式创新**：性转视角 / 都市故事搬进年代背景（时代互换）；② **题材融合**：主线 + 地域特色 + 群像喜剧（《东北年代之我的大腰子》打法）；③ **人设创新**：打破非黑即白，无绝对坏人；④ **关系创新**：把熟悉冲突放进新关系容器〔S6〕。
- [行业2026] 听花岛转型判断：从俗套到创新、从情绪到情感、从工具人到扎实人物、从悬浮到生活感——3.0 阶段"离谱剧情几乎不可能再成爆款"〔S9〕。**AI 剧若只卷套路不卷人物，会最早被观众抛弃。**

### 1.4 立项即对齐评级四维（红果/版权中心评审口径）

故事完整性 / 人物塑造 / 价值观导向 / 市场适配（business.md §3.2 材料组织法）。编剧动作：开写前就把"完整性"写成总大纲+结局纲要（**不烂尾是硬承诺**），把"导向"写成主旨一句话，别等质检兜底。

## 2. 人物设计：冲突不是情节给的，是人给的

### 2.1 主角欲望与缺陷（麦基母规则）

- **欲望 = 可被拒绝的可见目标**："想活"不可被拒绝（无戏）；"想让师父当众承认她"可以（有戏）〔S1；director.md §1 同口径〕。
- **缺陷 = 欲望的刹车**：主角必须有个性缺陷让 TA 无法一步到位（傲慢、自卑、心软、守旧），缺陷在风暴段被撞碎，弧光才有材料。
- **自觉欲望 vs 不自觉欲望**：[经典] 主角追着自觉欲望跑（报仇），真正需要的是不自觉欲望（被爱/原谅自己）；结局的"绝对而不可逆的变化"来自两者合流〔S1〕。
- **鸿沟引擎**：[经典] 主角每次采取"从自己主观视点看最小保守的行动"，世界却报以比期望更强烈或截然不同的反应 → 主观与客观之间裂开鸿沟 → 主角被迫加注、承担更大风险 → 戏就向前〔S1〕。**编剧自查：本场主角的行动有没有撞上鸿沟？没有 = 这场是过场。**
- **欲望价值与风险成正比**：[经典] 不愿冒有所失风险的欲望不值一提，故事会乏味〔S1〕。赌注必须写"会输掉什么具体的东西"。

### 2.2 人物弧光与主控思想

[经典] 主控思想 = 故事高潮证明的那句话（"执念比天道更难破"）；角色弧 = 主控思想在人物身上的投影。弧光三件套写进人设卡：起点价值 → 裂口事件 → 终点价值。例：`以宗门为天（信）→ 被宗门献祭（裂）→ 以自己为天（不信→重建信）`。起点与终点价值观必须不同，否则人物没变化，评级“人物塑造”维必扣分。
国际弧光母版〔S19〕：主角弧 = 在**主题 ↔ 反主题**之间的位移——开局抱住旧信念（反主题），编剧的活是不断问“此刻对她最狠的事是什么”并做下去，直到低谷：旧信念被证伪、新信念还不敢信——**低谷的成因是角色迷失，不是页码到了**；结局不是“我懂了”，而是用**行动**证明新信念（接受即行动）。与上表“起点→裂口→终点”同构，国际版额外要求把主题句与反主题句各写一行，钉在人物卡上。

### 2.3 四层反派体系（递进式对抗）〔开源 S12 结构，本库采用〕

| 层 | 定位 | 活跃时段 | 功能 |
|---|---|---|---|
| 小反派 | 日常对抗（刁难的表妹/恶仆/市井小人） | 前 1/4 | 制造前段爽点素材，教观众"站在主角这边" |
| 中反派 | 阶段威胁（商业对手/情敌/中层长老） | 前 2/3 | 给主角阶段性胜利与阶段性失败 |
| 大反派 | 核心对抗（幕后黑手/家族敌人/魔尊） | 中后期 | 承载主线意志，主角欲望的真正阻力 |
| 隐藏反派 | 终极反转（身边最信任的人） | 后 1/3 揭露 | 全剧最大情绪炸弹，回收所有"不对劲"的伏笔 |

纪律：**每一层反派都是“同样想要东西的人”**（[经典] 冲突优先是两个人想要同一个东西〔S1〕），不是脸谱化坏人；大反派最好有让主角“照见自己”的镜像设计。
国际升维〔S17〕：Truby 七步把对手设计成“直接反对主角欲望的人”（desire 之后紧接 opponent）——不是坏蛋，而是与主角抢同一件东西且**自认正义**的人；四角对立（four-corner opposition）更进一步：让 ≥4 股各自“有理”的意志同场互撞，比善恶二元复杂得多。**接法（不冲突）**：§2.3 四层 = 纵向升级阶梯（中国实务，管全剧推进）；四角 = 横向同场意志（国际工具，管单场高潮）——最贵的一场戏，让 4 个“都觉得自己对”的人同框。
[行业] 反派定爽感天花板〔S20〕：首场戏就给反派贴一个观众一眼认得的“道德红标”，同集“正面碾压 + 侧翼捅刀”双线夹击；**反派独白一律删——解释会稀释仇恨**（与 S5“反派算计句式指纹”同向，两条都收）。

### 2.4 配角功能化 + 扎实化（两句话都要）

- **功能化**：每个配角一句话回答"TA 在主角弧光的哪一步起作用"（提醒者/诱惑者/试金石/温情锚点）。功能不明 = 删。
- **扎实化**：[行业2026] 听花岛"从工具人进化到扎实人物，主角配角都要有完整小传，哪怕配角也要写"〔S9〕。**AI 剧尤其如此**：配角一张脸反复出现，没小传就会"漂"，一致性救不回来。
- **人物即冲突清单**：配角 = 主角欲望的阻力（敌）/助力（友）/镜像（亦敌亦友）；全剧任意两人同框，都要能说出"这两人此刻各想要什么"。

## 3. 结构与节奏：宏观定盘，微观定死

### 3.1 经典三段在短剧的翻译

- [经典] 三幕（悉德·菲尔德）：第一幕建置（前 10 页立人物/前提/环境）→ 情节点 I（不归路）→ 第二幕对抗（中点 = 最大挫折或转折）→ 情节点 II（推向决战）→ 第三幕结局（至暗时刻 → 高潮 → 收束）〔S2〕。
- [经典] 八序列法（Frank Daniel）：幕与场之间藏着一层——**8 个 10–15 分钟的 mini-movie，每个序列有自己的小起承转合，结尾"部分解决：回答当下问题、同时开出新问题"，把观众拽进下一序列**。它存在的理由正是"第二幕 60 页写不动"——拆成 4 个 15 分钟就写得动〔S3〕。**短剧翻译：序列 ≈ 5–10 集的情绪单元；编剧不写"第 3–40 集"这种无主任务，只写"这个序列的戏剧问题是什么、第几集部分解决、开什么新问题"。**
- [行业2026] 短剧黄金结构骨架（听花岛拆解口径）：第 1 集高能开场 → 第 3 集反转强化情绪张力 → 第 5 集矛盾升级拉留存 → 第 10 集终极反转引爆〔S11〕。

### 3.2 四段式节奏曲线（短剧专用，替代三幕比例）

**起势(15%) → 攀升(30%) → 风暴(35%) → 决战(20%)**〔开源 S12，按总集数等比缩放〕；
红果官方课同向口径：80–100 集 = **1–10 集黄金窗口**（立主线+最强看点；仇恨/委屈须开篇建立）→ **11–30 集稳固发展期**（主线实质推进，禁停滞重复）→ **31+ 高潮收束期**；"复仇/逆袭三五集一个小高潮、十集一个大高潮"〔S4〕。两口径对齐使用：段边界取整、小高潮按段内 3–5 集节奏排。
国际节拍对齐〔S18〕：好莱坞节拍表折算成百分比后与中国四段同构——Catalyst ≈ 起势内(~10%)、Midpoint(50%) 伪胜/伪败并加注、All Is Lost(~68%) 全剧至暗、Break into Three(~77%) 进决战、Finale = 决战段。“至暗时刻”写的是角色迷失而非页码（Mazin：没有三幕，只有“你的故事”这一幕〔S19〕）。**节拍表是诊断尺不是模板**（August：所谓结构问题，多半是观众迷路 = 某处意图缺席〔S19〕）——自检时逐拍对照找缺失，不按表填肉。

### 3.3 单集微结构（每集都按秒设计）

- [行业2026] 听花岛按秒拆解：**前 3 秒黄金钩**（强情绪冲突或悬念，决定滑不滑走）→ **6 秒进冲突** → **10 秒点悬念** → **第 1 分钟给足爽感**（不拖沓直接高能）→ **3 分钟完成一次情绪闭环**〔S11〕。
- [行业2026] 红果官方课：单集 1–3 分钟 = **前 30 秒制造停留理由 → 中间 1 分钟干货（推主线/关系/伏笔）→ 末 30 秒悬念/未完成动作/反转**〔S4〕。
- [AI落地] AI 剧 75–90 秒节奏更稳：0–10s 钩子重建情境 → 10–55s 升级（一件事改变、赌注升高）→ 55–75s 悬念处切断，**绝不在解决处切断**；单集 2–5 场戏，场景切换越少越省一致性命门〔S13 参照 + AI 语境〕。
- [行业2026] 情绪节拍器总纲：创作者是观众的情绪管理大师，管住观众何时紧张、何时松气、何时哭、何时笑〔S4〕。
- 国际竖屏引擎（60–90s 同款，可整段替换使用）〔S20〕：**Hook 0–15s** 引爆（中国同行称“爆炸点”，可把全季最炸一镜塞进前 15 秒当内建预告）→ **Friction 15–60s** 阻力必须**可拍**：门卡刷不过 / 会已开 / 门打不开——“如果障碍是段独白，你没有障碍，只有停顿” → **Spike 60–90s** 证据级转折重估全场——静音后消失的 spike 只是音量，不是转折 → **Button 末 5–10s** 在问题处切断，比“安全点”早 2 秒。四拍引擎与红果 30+60+30 同构：Hook≈前 30s、Friction+Spike≈中段干货、Button≈末 30s 悬念。

### 3.4 集数配比与卡点（机器可查阈值，与 content-standards §0.3 同一套口径）

| 项 | 阈值 | 出处 |
|---|---|---|
| 🔥 重点集（大高潮/情绪峰值） | 全剧 **25–35%** | 〔开源 S12〕 |
| 💰 付费卡点 | 全剧 **10–15%**；**首卡约第 8–12 集**；前 10 集 ≤2 卡点；尾段 ≤2 卡点；卡点间隔 ≥5 集 | 〔开源 S12〕 |
| 反转钩（全剧级反转） | ≤5–7 次（全剧） | 〔开源 S12〕 |
| 高潮间隔 | >8 集无高潮 = 致命；结局拖沓 >3 集 = 致命 | 〔开源 S12〕 |

> 国际对照〔S21〕：ReelShort 免费放前 10–20 集再解锁（金币/周月卡，订阅已占观看端付费 60–70%）——“先给足再收钱”与国内免费平台逻辑同源；卡点位置都应押在“情绪刚上头”处，中外一致。

### 3.5 长短剧/网文节奏差异（网文出身者第一课）

[行业2026] 燕北血泪教训：首部短剧按小说思维写了 15 万字 → 拍成 167 集"长篇短剧" → 收藏 20 万、中下水平，根因是"节奏偏慢、篇幅过长、没摆脱小说叙事习惯"〔S6〕。差异三刀：
1. **长铺垫 → 即时冲突**：小说可花几章铺世界观，短剧开场十几秒必须让观众懂"这是关于什么的故事、为何值得看"〔S6〕。
2. **内心戏 → 外化动作**：心理描写、上帝视角旁白全部翻译成可演的微动作/眼神/精炼对白（OS 是拐杖不是主力，见 §5.2）〔S6〕。
3. **作者视角 → 观众视角**：简单直给；"写着写着就小说化"是复发性职业病，每集自检一次〔S6〕。
对照实验：小说能靠"信息差"吊 3 章，短剧一集吊不住就换下一部剧了——**短剧的"钩"比网文的"章末悬念"更短命、更刚需**。

## 4. 钩子系统：每集结尾的唯一任务

### 4.1 五钩子设计与全剧配比〔开源 S12 结构，配比参考值〕

| 钩子 | 机制（观众为什么点下一集） | 参考占比 | 设计要点 |
|---|---|---|---|
| 悬念钩 | "然后呢？"——未解问题 | 20–30% | 秘密/身世/计划成败，问题要具体可期待 |
| 反转钩 | "怎么可能？！"——认知颠覆 | 5–15% | 全剧级反转 ≤5–7 次，省着用；需伏笔托底否则像硬编 |
| 情绪钩 | "气死/甜死/虐死我了"——情绪未闭环 | 30–40%（甜宠主钩） | 委屈没发泄、误会没解开、甜蜜被打断 |
| 信息钩 | "原来如此/竟然还有这层"——新信息 | 10–20% | 身份揭示、因果倒转、旧事翻案 |
| 危机钩 | "TA 要完了！"——即时危险 | 10–20% | 倒在门口/剑已出鞘/合同要签，掐在最险处 |

### 4.2 组合纪律（逐条可查）

- **同型钩子不连续 3 集**；同型爽点不连续 3 次；**每集至少 1 个情绪转折**（钩子之外的转折，不许靠一个尾钩撑全集）〔开源 S12〕。
- 钩子要"回答上一个问题 + 开出下一个问题"：[经典] 序列法的部分解决原则每集可用〔S3〕。纯解决 = 观众满足离开；解决 30% + 新悬念 70% = 追更。
- [行业2026] 情绪爆点前必须有压抑蓄力（爽点 = 压抑后的释放），无铺垫的爽是空的；"强冲突开局 + 身份反差"是番茄验证过的爆款开篇逻辑〔S4/S11 同向〕。
- 开头钩子（前 3 秒）与结尾钩子分工：开头钩 = 拉新人停留（可独立成短视频切片）；结尾钩 = 拽老人追更（必须依赖前文）。**每集都当“可切片”写开头——切片是免费宣发。**
国际钩子细则〔S20〕：尾钩细分 8 种掐法——危险 / 揭示 / 抉择 / 登场 / 背叛 / 倒计时 / 告白 / 反转，**轮换防麻**（cliffhanger fatigue：连用同类观众变钝；与“同型钩不连 3 集”是同一条规则的两副面孔）；一个冲突别一次解决，横跨 3–5 集逐集加新麻烦；尾钩 = 观众**答不出**的问题（“谁发的消息？”成立；“她气疯了”不成立——答案已在画面上）；开头钩要**静音可懂**：名字印错的收据、谎言中亮起的手机屏这类“证据画面”天然可切片，AI 剧尤其吃这套。

## 5. 台词手艺：字少、话里有话、听声辨人

### 5.1 短：单句 8–12 字上限

- [行业2026] 听花岛拆解热门短剧：单句台词平均 **8–12 字，最长不超 15 字**——"多一个字观众可能觉得啰嗦，少一个字节奏可能不对"〔S11〕。
- [行业2026] 红果官方课：台词"字少精准"，**忌 5–6 行以上长台词、忌大段旁白**；紧张时台词短促如密集鼓点，抒情时留白〔S5〕。
- **朗读砍肉法**：写完分角色大声念，拗口即改；念完试着砍掉 1/3，核心信息还在就大胆砍——删掉感叹词、重复强调、观众能脑补的说明〔S5〕。
- **中外差异（台词字数）**：8–12 字是**竖屏派生纪律**（密度 × 语速 × 拇指时代），不是全球通则——好莱坞母规则是“每句台词都在执行一次情绪意图”〔S19〕：Scriptnotes 把对白按模式分 **neutral / emotional / declarative** 三档，同场两人必须**模式错位**（一个冷静一个炸、一个理智一个崩溃）才有戏；两人同模式 = 各说各话的独白。执行顺序：**先定本句要改变对方什么情绪（国际母规则），再压到 15 字内（中国纪律）**。

### 5.2 潜台词：不说透 + OS 不是拐杖

- [行业2026] 燕北："能通过对白表达的绝不用画外音，能用表演呈现的内心活动绝不用独白"〔S5〕。**OS 滥用 = 剥夺观众思考空间 = 消灭悬念张力**（官方课反面案例：整段 OS 自我解释"我穿越了我要夺回家产"，改成盯着日历瞳孔骤缩 + 一句"我成了早逝亲妈？！"）〔S5〕。
- 潜台词写法：嘴上说的（字面）与心里真的（目的）各写一句并排，取两者之差演；"红着眼笑着说没事"这类口是心非必须显式写进剧本，AI 默认字面脸〔director.md §2.2 同口径〕。
- **台词 = 行动不是信息**：一句好台词同时是"揭示信息 + 制造冲突 + 做决定"（"你父亲不是病死的，是被害的"——一句三用）〔S5〕。

### 5.3 人物语言区分度：听台词认人

[行业2026] 台词是人物性格最直接的外化：同样拒绝，直率的人说"不行"，深沉的人委婉推脱，怯懦的人先道歉再找借口〔S5〕。可执行做法：
- **每人一句口头禅 + 一个语速/用词特征**（方言点缀、行业术语、爱用反问/爱下结论），写进人物圣经并全局一致。
- 古装/玄幻守时代语感与世界观：不给唐朝人说网络热梗（除非喜剧刻意设计）〔S5〕。
- 反派台词自带“算计与虚伪”的句式指纹，正派台词带“担当与直给”——语言指纹即人物立场〔S5〕。
- 国际同款判据〔S19〕：August 判断编剧高低的**第一眼是角色声音**——纸上每个人必须 distinct / alive / unique（即 §5.3 遮名测试的国际原版）；对白不是“偶尔被打断的独白”，是角色试图**改变对方情绪状态**的行动；交代信息守“听过一次不再听第二遍”——用反应代替复述（听完的人只回一句“那也太疯了”——“我知道，不用你告诉我”）。

### 5.4 金句工程

单集 1 句可截图台词（记忆点/传播点）：短、带态度、可脱离剧情成立（"执念比天道更难破"）。听花岛编剧中心制下，"编剧版"剪辑保留台词原意（S9）——金句是编剧在成片里最后的署名。

## 6. 爽点与情绪：密度、配比、蓄放

### 6.1 爽感矩阵（8 类要素按题材配比）〔开源 S12〕

| 爽感 | 机制 | 主力题材 | 配比纪律 |
|---|---|---|---|
| 打脸 | 反派挑衅→主角反杀 | 逆袭/复仇/都市 | 同型不连续 3 次 |
| 逆袭 | 低位→高位跃迁 | 男频/重生 | 跃迁要付出代价才可信 |
| 甜宠 | 关系推进/偏爱 | 女频情感 | 甜虐交替，纯甜会腻 |
| 虐心 | 求不得/误会 | 虐恋/古言 | 虐要有"出口预告"，纯虐弃剧 |
| 悬疑 | 真相逼近 | 悬疑/探案 | 信息给节奏：挤牙膏式 |
| 燃 | 信念/团战/大场面 | 玄幻/仙侠 | 配 BGM 位与名场面镜头位 |
| 搞笑 | 包袱/错位 | 喜剧/年代 | 笑点从人物性格长出来，不硬塞段子〔S5〕 |
| 感动 | 共情/牺牲 | 全题材辅料 | 全剧 ≥3 种爽感类型才不单调 |

**全剧爽点类型 ≥3、每集 3+ 情绪点（小起落）、每分钟 3–4 个情绪爆点（爆款密度参考）、爽点前必蓄力**（压抑→释放节拍：受辱→隐忍→证据→反杀，四拍一循环）〔开源 S12 + S11 同向〕。
国际纵轴〔S21〕：ReelShort 创始人 Joey Jia 三型故事论——plot-driven 属于电影、character-driven 属于剧集、**emotion-driven 天然属于手机竖屏**（“人们没准备好用手机消化复杂故事”）；中国短剧的“情绪价值密度”，在国际的正式名称就是 emotion-driven，二者同义。
国际横轴〔S20〕：释放强度 = **累积不公 × 反转的公开度**（私下胜利只解馋，公开反杀才上瘾——“打脸必须在场有见证人”由此而来）；情绪成瘾循环 = 伤害 → 安慰（一个小的真瞬间）→ 更大威胁，安慰未落定威胁已升级（本库“压抑→释放”四拍的国际升级版，多一拍“小暖点”缓冲）；题材旋钮：甜宠多用小惊吓 + 长痛感 + 公开被选择，复仇 = 长羞辱走廊 + 一次巨型公开清算，男频爽剧 = 锋利小转折 + 安静的权力翻转（与 §6.1 矩阵对照使用）。

### 6.2 情绪价值 vs 情感价值（2026 精品化分水岭）

[行业2026] 听花岛判断：短剧 1.0 粗糙快餐 → 2.0 精致快餐（制作升级但逻辑悬浮）→ **3.0 精致产品：反套路、重逻辑、像文艺片；悬浮叙事、老套情节、降智剧情正在快速失效**；四大转型方向"从情绪到情感、从工具人到扎实人物"〔S9〕。→ **爽感管留存，情感管口碑与评级；纯爽无情的剧本评级上限封死在"市场适配"单维。** AI 剧想进精品评级：在爽感矩阵外，每部留 1 条"情感暗线"（亲情/执念/愧疚）贯穿全剧，风暴段给它一场无爽点的重场戏。
中外差异（评级）：“价值观导向”是中国平台评级四维的硬闸门（§1.4），国际无对等官方维度——冲国内评级必须主动过这一关，出海只需满足当地内容政策、放宽到“平台红线级”即可。

## 7. 网文 → 短剧改编方法论（novel-agent 自产 IP 的变现手艺）

> 62% 爆款来自番茄 IP 改编〔数据 S15〕——改编不是退而求其次，是市场主航道。以下为燕北工作室 + 行业通法〔S6〕的浓缩执行版。
> 国际同逻辑〔S21〕：好莱坞与 ReelShort 都把“已验证 IP / 续集”当风险对冲（MPA：爆款系列是收入第一驱动）；ReelShort 自制 + 授权并行，但 >90% 营收来自**自制**——授权中国剧英配也能打，说明**改编的工序可以外包给 IP，改编的手艺必须自备**。番茄短故事“数据验证后改编成功率 >40%”（§1.1）与好莱坞“改编降开盲盒风险”是同一个商业判断。

### 7.1 流程五步

1. **反向拆解训练手感（新人/模型都适用）**：找 2–3 部平台爆款，1:1 还原成文字剧本，强制用编剧视角看每一秒画面对应的文字；拆解 2–3 部后对"格式+镜头语言"才有手感〔S6〕。→ 鲸影执行：改编任何 IP 前，先让模型拉片 1 部同题材爆款并输出结构报告。
2. **主线提炼做减法**：几十万字小说先揪出**唯一一条**最富戏剧冲突与期待感的主线，支线全砍；主线不清晰 = 拒稿第一原因〔S6〕。判断法：把每条线讲成一句话，问"去掉它观众还追吗"。
3. **选 IP 看"潜力股"不看顶流**：热门 IP 竞争白热，成熟编剧出手更快；找主线清晰、情绪饱满、人设鲜明、适合视觉化的腰部书〔S6〕。自有 IP 同理——先自测"能不能 10 秒讲清 + 有没有连续 30 集的冲突燃料"。
4. **写大纲再写集**：先交"故事大纲 + 核心期待 + 主要人设"三层材料，过审再动分集，禁止直接写集〔S6〕。
5. **逐集重写不是搬运**：原著每章 3000 字 ≈ 短剧每集 1000 字，压缩率 ~3:1；保留的是"事件与情绪"，重写的是"结构、节奏、台词"。

### 7.2 改编取舍清单（逐项打勾才动手）

- [ ] **开篇重写**：原著黄金三章 → 短剧黄金 3 秒；重生文直接开场给"背叛/死亡/重生/反击"四连，别从"前世铺垫"开始〔行业 蛙趣拼文等改编实务同向〕。
- [ ] **长铺垫砍掉**：世界观交代压进台词与背景动作，不设交代集。
- [ ] **爽点浓缩**：把原著散在 50 章的打脸/反转按"每集 3+ 情绪点、3–5 集一小高潮、10 集一大高潮"重新排布〔S4 口径〕。
- [ ] **人物精简**：主要出场角色 ≤15；功能重复的合体；配角只留四种功能（敌/助/镜/锚，§2.4）。
- [ ] **心理描写外化**：所有"内心OS段"转成动作+眼神+短台词（§5.2 手法）。
- [ ] **价值观顺一遍**：原著可写"以暴制暴爽完即止"，短剧要"爽完之后有代价/有底线"，否则过不了立意导向（content-standards §0 R1/R3）。
- [ ] **检查结局可拍性**：原著大场面如果 AI 生成成本爆炸（水下/千人战争/巨物），风暴段提前替换等效冲突（producing.md §1.2 落地性口径）。

## 8. 剧本医生自检：交付前五维体检 + AI 味净化

### 8.1 五维评分（每维 10 分，50 分制；≥38 进 storyboard，≥45 可直接投拍级）〔开源 S12 评级表，鲸影采用〕

| 维度 | 查什么 | 失分重灾区 |
|---|---|---|
| 节奏 | 场景切换节奏、信息密度、前 30 秒入戏、末尾钩子 | 无效嘴炮拖沓、支线跑偏、冲突刚起就结束〔S4 避坑四则〕 |
| 爽点 | 爽感密度、情绪高潮设计、蓄力-释放节拍 | 同型爽点连 3、无压抑直接爽、全剧爽点类型 <3 |
| 台词 | 语言个性化、单句长度、金句、OS/VO 滥用 | 5–6 行以上长对白、大段旁白、人人一个腔调〔S5〕 |
| 格式 | 场景头/动作/台词标注、镜头提示、可拍性 | "小说化"叙述段、无动作提示、演员不知怎么演〔S6〕 |
| 连贯 | 人设一致、前后集衔接、伏笔回收、主线推进 | 人物崩人设、卡点无承上启下、伏笔烂尾 |

评级：45–50 卓越 / 38–44 优良 / 30–37 合格需改 / 25–29 结构性重做 / <25 重写。每份报告输出：五维表 + 亮点 3–5 个 + 问题分级（⛔阻断 / ⚠️建议 / ℹ️微调）+ 修改优先级排序。
国际医生尺（叠加在五维之上）〔S16/S19/S20〕：① 每场必须“转值”，不转的场直接砍（McKee：if a scene is not a true event, cut it）；② 被批“结构问题”先查**意图缺席**——观众迷路 ≠ 需要换模板（August）；③ Spike 静音测试：无声后什么也不剩 = 假转折（Real Reel）；④ 尾钩必须落在观众“答不出”的问题上（Iguanify 五查⑤）。

### 8.2 'AI 味'净化清单（模型产出必过这层，逐条扫）

- **去模板腔**：删"仿佛/似乎/某种/一瞬间/不由地"；删空泛比喻（"像流星划过夜空"级）；删排比三连与万能金句（"你永远不知道……"式）。
- **去套路句**：删"他/她的眼神里闪过一丝……"万能表情包；每个情绪动词必须指向**可被镜头拍到的动作**（心理形容词 → 可见体征：`五味杂陈` → `握紧又松开`），与 director.md §2.2 表演可执行原则同一套标准。
- **去万能描写**：背景描写必须带信息或情绪（能推进/能立人/能埋伏笔），纯装饰性描写整段删；删"总结性点题"——每场戏让观众自己悟，不靠 OS 旁白替观众总结（§5.2）。
- **语言指纹复查**：随机抽 3 句台词遮住人名，猜得出是谁说的 = 通过；猜不出 = 该角色语言未立（§5.3）。
- **AI 段落试金石**：问"这段是一个具体的人（编剧）会写的吗？还是'最可能的平均文本'？"——平均文本 = AI 味 = 观众滑走。

### 8.3 与 content-standards 质检的关系（分工，不打架）

| 层 | 管什么 | 谁执行 | 何时跑 |
|---|---|---|---|
| 本文件 §8 | 写得好不好（手艺五维） | 编剧模型自检 + 剧本医生 | script 交付前 |
| content-standards.md | 对不对（红线/合规/评级维度阈值/卡点数值） | 规则轨 + LLM judge 双轨 | 文本段之后、上传前 gate |

顺序：**先过剧本医生（手艺关）再过内容质检（合规关）**——手艺不过返工改稿，合规不过阻断上传，两关独立、各自留报告。评级四维对齐见 business.md §3.2。

### 9.3 剧本医生自检表（§8 落地为勾选，交付时随附）

- [ ] 节奏：前 3 秒有钩；本集每场都在推主线/关系/伏笔，零过场（§3.3）
- [ ] 节奏：单集 2–5 场戏；结尾在悬念处切断、不在解决处切断
- [ ] 爽点：每集 ≥1 情绪转折 + 3 情绪点；爽前有蓄力；同型不连 3
- [ ] 台词：全句 ≤15 字为绝大多数；无 ≥5 行对白；无大段 OS/VO
- [ ] 台词：抽 3 句遮名可辨人；潜台词（说的 vs 真的）在场
- [ ] 人物：本场每个在场者"想要什么"可回答；反派四层递进未跳层
- [ ] 连贯：人设卡一致；上集尾钩本集已回应；本集埋的伏笔记入伏笔台账
- [ ] AI 味：§8.2 五条扫过，零命中
- [ ] 格式：可拍（导演能懂机位/表演/情绪），无"小说化"叙述
- [ ] 合规预检：无红线词汇/情节（正式闸门在 content-standards，此为先检）
- [ ] 五维打分：节奏__/爽点__/台词__/格式__/连贯__ = __/50（≥38 放行）
- [ ] 国际尺：每场转值、静音后 spike 仍在、尾钩=观众答不出的问题、台词模式错位（§8.1）
