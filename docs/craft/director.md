# 顶级导演 skill：AI 仿真人剧导演方法论

> 岗位知识库 · 鲸影 AI 仿真人剧生产管线（D:\CY\dsh-video-studio）
> 被引用场景：storyboard 镜头设计 / shot assets 镜头指令 / video 生成 prompt / final cut 成片质检。
> 一句话心法：**AI 仿真人剧的导演工作 = 用镜头把"情绪转折"讲清楚，同时让观众的眼睛在每个画面上找不到穿帮。**
> 评级对标：抖音版权中心高评级仿真人剧（单部保底 90–360 万）。评级死线三条：① 角色一致性 ② 真人感（微表情/眼神不穿帮）③ 题材安全区。
> 题材安全区速查：都市情感、长时间面部特写 = **高风险**；玄幻/仙侠/大场面 = 安全区。镜头设计天然向安全区倾斜（竖屏靠脸吃饭的张力见 §3.1）。

## 0. 管线定位与导演产出物

| 阶段 | 谁在干 | 导演的产出物 |
|---|---|---|
| story | LLM（编剧视角） | 主题、主角欲望、核心冲突 |
| script | LLM（编剧+导演） | 每场"戏卡"、台词潜台词 |
| storyboard | LLM（导演） | 镜头表：镜号/景别/内容/表演指令/意图 |
| master asset → shot assets | 多供应商图像 AI | 分镜素材、一致性绑定（@绑定 ≤50 参考） |
| video | Seedance 2.5 / Kling 3.0 / 即梦 / 可灵 | 镜头 prompt（表演+运镜+声音 cue） |
| final cut | 剪映草稿 / ffmpeg | 成片 + 导演抽检意见 |

导演决策只落在三类文本，本 skill 把三类文本全部模板化：**戏卡**（一场一卡）→ **镜头指令**（一镜一段）→ **验收意见**（一集一表）。
[行业2026] 听花岛对导演岗的启示："短剧最重要的不是短，而是密度：信息密度与情感密度必须极高，每秒都要有情感推进，不能有任何冗余"（出处：投资界《一家头部短剧公司的 37 个秘密》，2025）；其导演熟稔"用哪个焦段拍自家哪个演员最好看"——对应到 AI 管线 = **导演必须熟稔自家 master asset 与生成器脾气**（出处：新榜《24 个要点，揭秘听花岛的爆款短剧制作密码》）。

## 1. 导演思维起点：主题 → 欲望 → 冲突 → 一集一个导演意图

剧本回答"发生了什么"，导演回答"**观众此刻应当感到什么**"。自上而下四层，每层在生成前定死：

- **主题**：整部剧要证明的一句话。例：《××仙途》= "执念比天道更难破"。
- **主角欲望**：主题的人格化。每场戏先问"此刻 TA 想要什么"——要具体、可见、**可被拒绝**（"想活"不可被拒绝；"想让师父承认她"可以）。[经典] 冲突的动力来自角色"想要"，阻力优先是另一个"同样想要东西的人"（编剧通识，见罗伯特·麦基《故事》体系对"欲望×阻力"的定义，本库按此执行）。
- **核心冲突**：欲望 × 阻力。没有第二个人想要的东西 = 这场戏是过场。
- **一集一个导演意图**：一句话写死本集唯一要让观众"体会到"的情绪或领悟。写不出 = 退回 script。

【分镜强制规则】storyboard 输出头部必须含：
`导演意图：<一集一句话：观众看完本集最深的感受>`
没有这一行禁止拆镜头——它决定本集所有取舍。

导演意图质量 3 问：
- [ ] 是"感受"不是"情节"？（"她误会了男主"是情节；"憋屈到想摔手机"是感受——要后者）
- [ ] 能被 5 秒无台词镜头独自承担吗？（意图必须有一部分靠画面说话）
- [ ] 与主题同一方向吗？（本集意图 = 主题在本集的投影）

意图取舍纪律：与意图无关的戏砍掉或压成 1 个交代镜。一集 5–7 场戏，只留 3–5 场"有意图的主场戏"+ 1–2 场过场，其余沉底或进 montage。[行业2026] 密度不是多塞情节：听花岛按秒拉片发现神剧每秒都在推进情感（出处：同 §0），空场与废戏是评级最大损耗。

## 2. 从剧本到镜头：一场戏的导演拆解

### 2.1 戏卡：拆解五问（一场一卡，进 script/storyboard）

| 字段 | 问题 | 输出要求 |
|---|---|---|
| 想要 | 主角此刻想要什么 | 一句可见目标，可被拒绝 |
| 阻力 | 谁/什么在挡 | 必须是人（或拟人意志） |
| 转折 | 情绪/权力在哪个 beat 反转 | 精确到一句台词或一个动作 |
| 潜台词 | 嘴上说的 vs 心里真的 | 各一句，逐字写出 |
| 情绪顶点 | 全场最"响"的一下 | 只有 1 个，其余让路 |

### 2.2 [AI落地] 表演指导：微表情/眼神/肢体怎么写进 prompt

总原则：**视频生成器只能执行"可被看见的表演"。** 一切心理描写（"内心挣扎"）先翻译成可见动作才能进 prompt。[经典] 反应与潜台词由"听者的表情"送达，是蒙太奇情绪机制（Kuleshov Effect：同一张脸接不同上下文，观众读出不同情绪——出处：Reaction shot/Kuleshov effect 词条，filmmakersacademy.com）。

**眼神第一。** 观众识破 AI 的 No.1 开关是眼神（焦点虚、视线无目标、双人同框互不聚焦）。眼神指令四要素：方向/对象/看不看镜头/何时变。
公式：`[谁] 望向[目标]，眼神[状态A→状态B]，[微顿/移开/垂眸]`
例：`林澈望向远处山门，眼神由希冀转为决绝，缓缓垂眸`——可执行且情绪在场。

**表情给"可生成情绪"动词，不给心理形容词。**
- ✅ 可执行：震惊、隐忍、杀意、心虚、故作镇定、欲言又止、落寞、警觉
- ❌ 不可执行：五味杂陈、百感交集、复杂的眼神
微表情对视频模型过细，**表情至少给到"中景可读"强度**，宁给"眼尾泛红"这类可见体征，不给"嘴角几不可察的上扬"。

**情绪 1 主 + 1 抑制**：高级表演 = 情绪被压制后的泄露（[经典] 影视表演基本功；AI 语境翻译）：主情绪给台词语气，泄露给肢体——
`语气平稳` + `指尖轻颤 / 喉结滚动 / 握紧又松开`。一组压一组，戏就出来。

**肢体指令三档精度**（按景别选档，不越级）：全身动作（全景/中景）；上肢动作（中景/近景）；微动作（只给特写：指尖、喉结、呼吸、睫毛）。

**口型-语义锁**：表情不能与台词打架。"微笑说狠话""红着眼笑着说没事"必须写进指令——不写，模型默认字面脸。

### 2.3 表演指令模板（整段直接进 shot prompt）

`[角色@角色ref]，[景别][角度]，表情[主情绪]，视线[方向/是否看镜头]，动作[档位]，情绪基调[主情绪]压[抑制情绪]；台词语气[平稳/颤抖/冰冷/带笑]`

### 2.4 每镜生成前自检
- [ ] 情绪词全是"动作级"表达，零心理形容词
- [ ] 眼神四要素齐
- [ ] 表情与台词语义不打架（或打架是刻意且写明）
- [ ] 肢体动作与景别匹配

## 3. 镜头叙事语言

### 3.1 景别 = 情感距离（选景别 = 选观众与角色的距离）

| 景别 | 情感含义 | AI 一致性风险 |
|---|---|---|
| 大远景 | 宿命、孤立、渺小、天地不仁 | 低 |
| 全景 | 处境、关系建立、动作场面 | 低 |
| 中景 | 对话关系、动作意图 | 中 |
| 近景 | 情绪、台词重点 | 中高 |
| 特写 | 内心、关键反应、证据（面部） | **高** |
| 大特写 | 眼神、手部、决定性细节 | **极高** |

[经典] 机位与景别就是电影语言的词法，"把摄影机放在哪、为什么放那儿，永远要服务于故事的情绪核心"（出处：Vilmos Zsigmond 语，转引自 ASC 杂志 Jay Holben《Shot Craft: Where Do You Put the Camera?》, 2020）；特写对表演的情绪放大远超全景，"戏的输赢往往在特写里"（出处：Sony Cine《The Cinematographer and Scene Blocking — Part 2》）。master shot（全景主机位）定全场 → 再进特写，是本库一镜到底之外的标准语法。
[行业2026] 竖屏物理限制反向塑造风格：竖幅天然排斥全景叙事、更聚焦"单一人物的脸和情绪"，台词必须更直给（出处：搜狐专栏《竖屏短剧的剧本逻辑，是一套完全独立的写作语言》）；抖音/快手对竖屏剧有"15 秒一个情绪锚点"的内容要求（出处：腾讯新闻《竖屏短剧选本与改编技巧》）。**推论 [AI落地]：竖屏戏近脸占比天生偏高，一致性命门全押在"脸"上——不是少用脸，而是把每张脸的时长/动作/角度控死在安全区（见 §6）。**
规则：一场戏全景开（交代处境），情绪顶点前推到近景/特写，说完退回中景。全片近景+特写占比建议 40–60%（竖屏业态），其中**纯正脸特写 ≤15–25%**，玄幻安全题材往下压。

### 3.2 对话镜头语法（[经典] 规则 + [AI落地] 简化执行）

- **正反打**：A 说话镜 → B 反应镜 → A 再说话。[经典] 反应镜是全片情绪的暗线——至少 30% 对话镜给听者（Kuleshov 机制，出处同 §2.2）。
- **过肩（OTS）**：绑定双人空间。[经典] 阿里洪《电影语言的语法》以"关系线"为轴，关系线一侧的机位三角形衍生出外反拍（过肩）/内反拍/平行/共同视轴五种基本机位（出处：中文版拆书，zhihu 专栏 272554527；原书第 2–3 章）。[AI落地] AI 正反打直接采用**锚点机位**：全景主机位 + A 侧过肩 + B 侧过肩，三锚循环，不叠自由运镜。
- **视线匹配（eyeline match）**：[经典] A 看画面右，B 必看画面左；同场不跳轴，否则角色看起来"各看各的"或同向（出处：LearnAboutFilm.com 180° rule 与 Filmmakers Academy "Eyeline Match" 词条）。双人同框近脸是 AI 眼神穿帮重灾区（§6.1）。
- **主观镜头（POV）**：切"角色所见"。情绪高潮用一次 POV 极有效。[AI落地] POV 不拍人脸 = 一致性零风险 = **安全区镜头，多用**。
- **180° 轴线与 30° 规则**：[经典] 摄影机保持在行动轴线一侧；两镜间机位角度差 <30° 会造成跳跃剪辑感（出处：LearnAboutFilm.com / Wikipedia "180-degree rule""30-degree rule"）。[AI落地] AI 生成的相邻镜头常出现机位"同一侧微移"的跳切感，两镜务必保证角度差 ≥30° 或景别/内容有明显变化。

### 3.3 运镜语义（camera move = 句读）

| 运镜 | 情感含义 | AI 语境注意 |
|---|---|---|
| 缓推 (push-in) | 逼近情绪、强调 | 面部特写时推 = 风险升高，推至近景止 |
| 拉远 (pull-back) | 抽离、揭示、孤独 | 安全，多用 |
| 横移/摇 | 扫描、关系、空间 | 全景安全 |
| 跟随 (follow) | 主观卷入、追逐 | 保持半身以上景别 |
| 升降 | 格局、命运 | 全景/大远景安全 |
| 手持微晃 | 紧张、纪实 | 晃幅写"微"级，过晃糊脸 |

[经典] 机位高度本身是语言：低于视线 = 抬升角色气势，高于视线 = 削弱（出处：同上 ASC《Shot Craft》）。[AI落地] 运镜指令写在 prompt 段首：`运镜：镜头自[起点]缓推至[终点]，水平，速度舒缓`。**不写运镜 = 固定机位**；固定机位是生成器最稳默认值，长对话优先固定。

## 4. 场面调度（Mise-en-scène）

### 4.1 单镜头三层信息（一镜三层，逐层写清）

- **前景层**：纵深/气氛/遮挡。**前景物避开人脸正前方**（半透明纱幔/剑鞘过脸是 AI 脸变形高发位）。
- **主体层**：戏的所在，表演指令给这层。
- **背景层**：环境叙事 + 群演。补戏不抢戏：竹林随风、远山雾起、城楼旗动。背景给情绪色调（冷=压制，暖=记忆）。

背景指令模板：`背景：[环境]，[天气/光线色调]，纵深[层次]，背景人物动作幅度小，不看向镜头`

### 4.2 群演逻辑（[AI落地] = 背景人物指令）

群演三不许：不直视镜头 / 不做主角同量级动作 / 不抢前景焦点。
群演指令模板：`背景人群[数量]，中远景，动作幅度小（缓行/交谈/驻足），面部细节弱化，不与主体互动`
纪律：群演与主角"有戏"时，单独给那个群演一个近景/过肩——禁止中景里同时要求主角+群演双向表情（§6.3 高危区）。

### 4.3 空间关系一致性（跨镜头）

- 场景 master（大全景）先定，后续所有镜头从它长出来：出口、柱子、谁站哪。
- 道具位置地图：每镜重写关键道具位置，压住 AI 道具漂移。
- 视线轴/进出场方向：A 左 B 右、左入右出，跨镜一致。[经典] 这正是"连续系统 continuity system"的目的——让分切镜头仍然是一个空间（出处：LearnAboutFilm.com "Continuity: Shoot and Edit so your Movie Makes Sense"）。
- 【storyboard 强制】多人场附文字"站位图"（A 东 B 西 C 北 + 机位 S1/S2/S3）作为全部镜头指令的空间基准，无站位图禁止发多人场任务。

## 5. 情绪曲线与节奏

### 5.1 每集 3–5 个情绪节点

一集要有情绪"形状"，节点可标：钩子入点（0–3s 第一镜给悬念/反常识画面）→ 升压点 1–2 个 → 波峰（≈60–75% 处，= 戏卡情绪顶点；波峰前必须放缓）→ 落点钩子（末 5s：意图回响 + 下集引子，通常特写眼神/物件/潜台词）。
[行业2026] 情绪曲线是可学习的结构：听花岛以"剧情热度预测系统"学习数百部短剧的情绪曲线自动生成最优剧本结构；对《请回答1988》写过 10 万字拉片报告，爆款按秒拆解（出处：人人都是产品经理《情绪印钞机》/ 投资界《一家头部短剧公司的 37 个秘密》）。[行业2026] 平台侧印证"每 15s 一个情绪锚点"（出处：腾讯新闻，同 §3.1）——本库一集 3–5 节点即其工程化版本。

### 5.2 张弛节奏

硬场面后必须接 1 个静场回收；连续两硬场疲劳、连续三文场流失。60s 内场面 ≤2 段，文戏段落间用 1–2s 空镜/环境音换气。[行业2026] 节奏与卡点、情绪爆点设计是官方编剧教程的专门章节（出处：红果短剧官方《短剧编剧教程》05《揭秘短剧节奏的设计密码》）；听花岛另在竖屏上开发"一镜到底"竖屏美学提升画面信息密度（出处：投资界 37 个秘密）。

### 5.3 静默拍出戏（无台词镜头清单）

无台词镜头 = 真人感放大器，也是 AI 雷区（没人说话 = 观众全在看脸和动作）。安全可执行的静默镜：
- 听者反应镜（§3.1，Kuleshov 机制）
- 背影戏：走向门/山/光，背影+环境声——一致性零风险且极煽情
- 手部戏：握紧/松开/抚剑/纸落地（手部特写一致性低风险，情绪顶点可放心落在手上）
- 空镜：香炉烟、雨打檐、剑入鞘——情绪转折前后各插 1 镜，给观众 2s 消化
- 定格/慢放：情绪顶点后接 1s 静帧或慢镜

【规则】情绪顶点前后各留 1 个静默镜；台词最密处反而是戏最薄处。

## 6. AI 特有导演问题：一致性、长镜 vs 短切、多角色

### 6.1 镜头风险分级表（决定预算与替代方案）

| 级别 | 镜头类型 | 处置 |
|---|---|---|
| 安全 | 大远景/全景、背影、剪影、POV、空镜、环境、兜帽/面具 | 正常生成 |
| 低风险 | 中景说话、缓行跟拍（半身）、手部特写、中远景动作 | 正常生成，@角色ref |
| 高风险 | 长时间正脸特写、转头≥90°、大仰角看脸、多人脸同框、剧烈动作、脸部光影骤变 | 单镜 ≤4s、固定机位、绑主像帧，或用背身/侧脸替代 |
| 极高风险 | 面部特写+转头、镜/水倒影人脸、遮挡物划过脸（发丝/手/面纱）、哭戏特写 | **规避/替代**：倒影拍"镜中的手/身"；哭戏拍低头耸肩+手背擦泪 |

**总原则：把戏导到生成器的安全区去。** 真人导演用"脸"表达的情绪，AI 导演用"脸+背+手+环境"轮换——脸只给最关键处。情绪顶点仍可给脸，但控时长、静态、少转头。

**AI 穿帮镜头分类库**（QA 逐类排查；storyboard 尽量规避）：
1. 五官漂移/脸型突变（逐帧比对 master 帧） 2. 手指/肢体数量错 3. 双人眼神不同轴 4. 口型与音轨错位 5. 倒影与正身不一致 6. 服装纹样/耳饰跨镜闪变 7. 文字乱码（招牌/符箓/竹简） 8. 群演僵尸化/主角与背景融合 9. 光影物理错误（影子方向、光源跳变）

[行业2026] 撞脸与合规警示：AI 短剧"一张脸演百剧"已成行业级差评点，观众集体脸盲；制作方拿真人多角度正脸照当"视觉锚点"正踩盗脸/买卖脸的法律与合规雷（出处：北京日报《AI短剧何以"一张脸演百剧"？》、知乎"AI 短剧面孔雷同"高赞讨论；合规素材倾向在增强，见 500 元一张脸的授权脸报道）。【鲸影纪律】master asset 只出自自有管线/合规授权素材，**禁止抓取真人照片当视觉锚点**——这是评级与法律双红线。

### 6.2 长镜头（Seedance 30s）vs 短切策略

[行业2026] Seedance 2.5 生产一线共识：**30s 的 prompt 是"拍摄计划/schedule"而不是"描述"**——不给时间表，模型就自己填空："第十二秒脸变了、道具瞬移"（出处：hoox.video《Prompt Seedance 2.5: Mastering the Art of 30-Second Videos》2026-08-07；atlabs.ai / novoads.ai 同结论）。可用框架六块：subject→action→setting→visual style→camera→audio，长镜必须带 [TIMELINE] 分段、末行 [LOCK] 形象锁（出处：同上）。

- **长镜头用武之地**：情绪连续戏（对峙/诀别）、大场面运镜展示、音画一体氛围段。情绪不断气是优势；代价 = 单镜越长后半段漂移概率越高（hoox 原文：faces change at second twelve）。
- **短切（2–5s）的本质是"重置机会"**：每次剪切 = 一次修正角色脸的机会。一致性不稳的角色戏、台词密集戏、多角色戏，一律短切。
- 决策规则（[AI落地]）：
  - 单角色静态情绪戏 → 可 6–12s 长镜（脸绑主像帧，写 [TIMELINE] 分秒段）
  - 单角色动作/转头/表情变化多 → 拆 3–5s 短切
  - 多角色同框 → 全程短切，禁长镜
  - 大场面运镜（无近脸）→ 30s 长镜大胆用
  - [行业2026] 生产纪律（出处：hoox/novoads）：一段长镜只做"一个状态变化"（开→关 之类），两个变化必半成品；音画一体下声音要写成 cue sheet（环境音/拟音/台词逐条列出、注明语言），不是一句"有氛围"；连续镜必须明写 `one continuous take, no cuts` 防模型自造剪辑点；末行 `全程同一角色形象，无外貌变化` = identity lock。
  - [行业2026] 画质复核（出处：hoox）：Seedance 2.5 API 实际输出上限 480p/720p（宣传 4K），交付 1080p 需走升级/超分链路——质检项 D5 依据。

### 6.3 多角色同框指挥

- **绑定分配**：参考额度按顺序加权、越前越强（[行业2026] 出处：atlabs.ai/morphed.app）→ 主角 + 关键服装/道具排最前；配角不绑或低权重——预算永远押给观众盯的那张脸。
- **单拍优先**：能拆单拍（A 说完→B 反应各成镜）就不做同框双表情。同框只留给"关系必须同框"（拥抱/对峙/并肩）。
- 同框指令先定关系再定画面：`[主角]居右前景[动作]，[配角]居左后景[动作]，配角略虚`。谁动谁静写明，双动必乱。配角只给单位置情绪（愤怒/平静/恐惧三选一），3/4 侧脸、视线偏向主角。
- 身体接触镜（拥抱/打斗）= 肢体穿插/五官错位重灾区，逐帧抽检，不行就换角度或前景遮挡。

## 7. 交付 Check：导演视角成片验收四问（final cut 前逐集过）

**Q1 意图清楚吗**
- [ ] 观众能说出本集"憋屈/爽/虐/燃"中哪一个？说不出 = 意图没立住
- [ ] 至少 1 个镜头（最好无台词）单独承担意图
- [ ] 波峰段与戏卡情绪顶点一致，没被剪平

**Q2 情绪到位吗**
- [ ] 每场主角的"想要"可见（台词或动作支撑）
- [ ] 反应镜 ≥30%，听者表情传达潜台词（Kuleshov，§2.2）
- [ ] 表情/眼神有没有被生成器"翻译丢"（脸到位但眼无神）
- [ ] 静默镜 ≥1 处，情绪顶点前后有换气

**Q3 节奏对吗**
- [ ] 3–5 情绪节点清晰，波峰 ≈60–75% 处
- [ ] 场面/文戏交替，无连续三段同类
- [ ] 开场 3s 有钩子，末 5s 有引子
- [ ] 无 2s 以上无信息空转（听花岛"每秒情感推进"，§5）

**Q4 有 AI 穿帮镜头吗**
- [ ] §6.1 分类库逐类过（五官漂移/眼神轴/口型/倒影/肢体/群演）
- [ ] 高风险镜逐帧抽检 ≥5 帧比对 master 帧
- [ ] 文字无乱码；音画同步可容忍（口型-语义锁，§2.2）

四问任一不过 = 该镜打回对应阶段（改 prompt 重生成优先于后期硬修），不先交片。

## 8. 完整示例：一场 30s 玄幻戏（§1–§6 全流程示范）

### 8.1 剧本节选
> 玄天宗外门弟子**林澈**，多年被当废物。宗门考核日，他敬重的师姐**苏晚晴**当众宣布与天骄**萧衍**结契。散场后林澈在雨中石阶拦住苏晚晴："是不是我永远追不上你？"苏晚晴答"你我殊途"。林澈雨中握紧断剑，转身离山。

### 8.2 戏卡（拆解五问）
| 字段 | 内容 |
|---|---|
| 想要 | 林澈要苏晚晴说出"不是"（一句认可/挽留） |
| 阻力 | 苏晚晴的"你我殊途"——她想要萧衍的庇护，与林澈的挽留互斥 |
| 转折 | "殊途"二字出口 + 她转身（beat：林澈幻想断裂） |
| 潜台词 | 林澈嘴上"我是不是追不上你"→ 心里"留我最后一点尊严的方向"；苏晚晴嘴上"殊途"→ 心里"再不走就要心软" |
| 情绪顶点 | 林澈握剑指节发白、雨滴自剑尖坠落（不给咆哮，给压到极点的静） |

### 8.3 导演意图
`导演意图：让观众替林澈感到"被放弃的憋屈"，并在其转身离开时生出"这口气迟早要还"的期待。`

### 8.4 情绪曲线（30s 分镜节奏）
| 时间 | 段落 | 情绪 | 节点 |
|---|---|---|---|
| 0–5s | 雨中石阶拦人 | 卑微恳求 | 升压点 |
| 5–10s | 苏晚晴背身答话 | 冷 | 铺垫 |
| 10–13s | "你我殊途"+转身 | 断裂 | 波峰起 |
| 13–22s | 林澈独留原地，雨声 | 憋屈内爆 | 波峰延续（静默主场） |
| 22–30s | 握剑→转身→背影拉远 | 决绝+余恨 | 落点钩子 |

### 8.5 镜头指令表（9 镜：7 短切 + 1 中长 + 1 远景收尾；[AI落地] 六块结构：主体→动作→环境→风格→运镜→声音）

| 镜 | 景别/运镜 | 画面与表演指令（可直接进 prompt） | 风险 |
|---|---|---|---|
| S1 | 全景/固定 | 雨中石阶，林澈自左下入画拦在苏晚晴身前，衣袍尽湿。冷雨青灰调，环境声：雨+风 | 低 |
| S2 | 近景/缓推 | 林澈@ref 抬脸，雨水沿下颌滴落，视线偏右上望苏晚晴，眼神恳求→紧绷，语气颤抖："是不是……我永远追不上你？"（时长≤4s 静态） | 高→控时 |
| S3 | 中景/固定 | 苏晚晴@ref 侧 3/4 背对镜头，不看林澈，目光远处；语气平稳冰冷："你我殊途。" | 中 |
| S4 | 特写(手)/固定 | 苏晚晴指尖在袖中收紧又松开（潜台词唯一泄露） | 低 |
| S5 | 近→中景/拉远 | 苏晚晴转身入雨幕，伞沿雨珠滑落；镜头缓拉（情绪抽离），雨声渐强 | 中 |
| S6 | 近景/固定 | 林澈@ref 原地垂首，湿发贴面，视线低垂，喉结滚动；**无台词，雨声占满**（3s 静态） | 高→控时 |
| S7 | 特写(手+剑)/固定 | 林澈手缓缓握紧断剑，指节发白，雨滴顺剑尖坠落（情绪顶点落在手上不拍脸） | 低 |
| S8 | 中景/跟随 | 林澈转身走向山门，脚步由慢到稳 | 中 |
| S9 | 大远景/拉远+升 | 林澈孤身下千级石阶，山门雨幕身后，天地苍茫 | 低 |

若改走 30s 长镜方案（仅限 S2→S8 单角色连续情绪段），[行业2026] 写法（出处：hoox 指南）：
`one continuous 30s take, no cuts` + `[TIMELINE] 0-5s 拦人…10-13s 她答"你我殊途"转身…13-22s 他独留雨中…22-30s 握剑转身离山` + 末行 `[LOCK] 全程林澈@ref 同一形象，无外貌变化，无多余人手`——并复核 720p 上限后决定是否走短切+超分。

### 8.6 一致性 / 风险处置说明
- 林澈独占 S1/S2/S6 三张近脸镜，全部 @绑定主像帧；S2/S6 各 ≤4s、固定机位、无转头。
- 情绪顶点不拍脸，落在 S7 握剑的手——避开哭戏特写高穿帮区，且比嚎啕大哭更贴"压到极点的静"。
- 苏晚晴两镜"不看林澈"视线轴统一（eyeline 一致）；同框仅 S1，其后全拆单拍。
- 钩子与情绪输出全在背影/远景/手部等安全区；多角色+台词场按 §6.2 禁长镜，采用 9 镜短切。

### 8.7 该场验收（§7 四问快速自检）
- Q1 意图：S7 握剑 + S9 背影独立承担 ✅
- Q2 情绪：S6 无台词静默镜给换气；S4 手部泄露苏晚晴潜台词 ✅
- Q3 节奏：波峰 10–13s（30s 短戏允许前移）；钩子在 S9 ✅
- Q4 穿帮：近脸镜限时限动；S2/S6 逐帧比对 master ✅
